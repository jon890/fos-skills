# 심각도 표기와 행동 규약

「분류」 단계에서 읽는다.
봇마다 표기가 달라도 행동 규약은 하나로 모은다.

**어느 봇이 어느 표기를 내는지는 저장소마다 다르므로 오버레이가 소유한다.**
아래는 표기의 형태만 적는다.

## P1 부터 P5

머리에 요약 표를 두고, 그 아래 「발견사항」 절에서 등급별로 항목을 나열한다.

```
**머지 가능** - P1 과 P2 없음

| 🔴 P1 | 🟠 P2 | 🟡 P3 | 🟢 P4 | ⚪ P5 |
| :-: | :-: | :-: | :-: | :-: |
| 0 | 0 | **1** | **2** | **2** |

### 발견사항

**🟡 P3 - 웬만하면 반영해 주세요 (작성자 판단)**

  - 항목 제목
    - 근거와 설명

### 잘 된 점
- ...
```

등급 문구는 봇이 스스로 적어 준다. 실측한 것만 아래에 옮긴다.

| 등급 | 봇이 적는 문구 |
|---|---|
| 🟡 P3 | 웬만하면 반영해 주세요 (작성자 판단) |
| 🟢 P4 | 반영해도 좋고 넘어가도 좋습니다 (선택) |
| ⚪ P5 | 그냥 사소한 의견입니다 (참고) |

**문구는 실제로 받은 리뷰의 소제목을 그대로 읽어 쓴다.**
P1 과 P2 는 아직 받은 적이 없어 여기 적을 것이 없다.

## Low, Medium, High

`분류: Low 1개` 처럼 등급과 건수를 적는다.

## 옛 표기 (오래된 PR, 다른 봇)

```
🔴 필수 수정: ...
🟡 개선 권장: ...
🟢 잘 된 점: ...
```

## 등급 대응

| P 등급 | Low·Medium·High | 옛 표기 |
|---|---|---|
| 🔴 P1, 🟠 P2 | High | 🔴 필수 수정 |
| 🟡 P3 | Medium | 🟡 개선 권장 |
| 🟢 P4, ⚪ P5 | Low | (해당 없음) |
| 「잘 된 점」 | (해당 없음) | 🟢 잘 된 점 |

## 행동 규약

| 등급 | 무엇을 하나 |
|---|---|
| P1, P2 | 반드시 반영한다. 남긴 채로 머지하지 않는다 |
| P3 | 반영할지 판단하고, 그 판단을 해당 스레드에 회신한다 |
| P4, P5 | 반영하지 않아도 되고, 판단만 회신해도 된다 |
| 「잘 된 점」 절 | 수정 대상이 아니다 |

회신은 지적 하나에 하나씩 단다. 판단을 적는 것도 회신이다.
반영하지 않기로 정한 P3 도 왜 그렇게 정했는지를 그 스레드에 남긴다.
