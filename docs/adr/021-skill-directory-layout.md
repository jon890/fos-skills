# ADR-021: 스킬 원본과 저장소 관리 영역을 나눈다

- **status**: `accepted`
- **대체**: [ADR-001](001-plugin-from-repo-root.md)의 루트 스킬 배치. 플러그인 소스는 저장소 루트를 유지한다.
- **결정**: 설치 스킬은 `skills/`, 내보내기 전용 원본은 `export-only-skills/`, Git 훅은 `githooks/`에 둔다. 스킬 전용 코드·훅·테스트는 소유 스킬 안에 둔다.
- **맥락**: 루트의 스킬과 도구·훅·보드가 같은 층에 쌓여 구조를 파악하기 어려워졌다. 기존 배치의 링크와 내보내기를 유지할 이점보다 탐색 비용이 커졌다.
- **대안**: 루트 배치 유지는 이동 비용이 적지만 복잡함이 남는다. 모든 스킬을 기본 `skills/`에 넣으면 내보내기 전용 원본도 자동 로드된다. 별도 플러그인 사본·호환 링크는 원본과 설치 경로가 갈라져 두지 않는다.
- **결과**: 매니페스트·스킬 탐색·CI·내보내기·설치 경로를 함께 갱신한다. 호출 이름과 팀 저장소의 `skills/<이름>/`는 유지한다. 옛 커밋 내보내기와 옛 설치 캐시 판정은 읽기 호환으로 지원한다. 개인이 만든 심볼릭 링크는 새 경로로 전환한다.
- **검증**: 격리된 설정 폴더에 설치해 설치 스킬만 인식되고 내보내기 원본은 로드되지 않는지, 캐시에서 형제 참조·공용 도구·검사기가 실행되는지 확인한다.
