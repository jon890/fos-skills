# 개인 문체 참조

「수신자와 문체」 단계에서 참조 파일이 없을 때, 만들지 정하려면 읽는다.

본인 명의로 나가는 글의 문체를 고정하고 싶으면 `~/.claude/references/work-writing-persona.md` 를 만든다.
**없으면 이 스킬은 미리보기 절차만 수행한다.** 문체 관련 지시를 건너뛴다.

## 두는 자리

문체는 사람마다 다르고 남의 문체를 강제하면 글이 어색해지므로, 이 저장소는 참조를 배포하지 않는다.

| 자리 | 두지 않는 이유 |
| --- | --- |
| 스킬 안 | 스킬을 옮기거나 심링크를 다시 걸 때 참조가 꼬인다. 개인 파일을 무시하는 규칙을 저장소가 따로 들어야 한다 |
| `~/.claude/rules/` | 하네스가 그 디렉터리를 전역 지침으로 무조건 읽어, 글을 쓰지 않는 세션에도 전문이 실린다 |

## 무엇을 적나

**본인의 실제 작성 이력에서 뽑는다.** 과거에 직접 쓴 업무와 댓글을 모아 반복되는 특징을 찾는다.

| 축 | 정하는 것 |
| --- | --- |
| 수신자별 모드 | 작업 로그, 대외 회신, 업무 본문처럼 읽는 사람이 다르면 문체도 다르다 |
| 문장 종결 | 평서체, 명사형, 존댓말 중 무엇으로 끝낼지 모드마다 고정한다 |
| 개인 습관 | 결론을 끌어내는 기호, 강조 방식, 링크를 붙이는 자리 |
| 하지 않는 것 | 사람이 쓰지 않는 표현이 나오는 지점을 적어 둔다 |

표기와 가독성 규칙을 따로 두고 있으면 그것을 덮어쓰지 않는다.
그 안에서 개인 문체를 정하는 문서로 쓴다.

## 본문을 쓰기 전에 읽는다

다 쓴 뒤 점검 항목으로 확인하면 늦다.
헤더와 표로 짜놓은 본문은 문체를 고치는 것이 아니라 처음부터 다시 쓰는 일이 된다.
