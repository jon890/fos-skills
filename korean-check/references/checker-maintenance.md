# 검사기 매핑 표 유지보수

`판` 과 `정점` 은 금지어로 등록할 수 없다.
검사기가 부분 문자열로 찾아 `판단`·`판정` 과 `그래프의 정점`·`수정점검` 까지 걸린다.

`재다` 도 활용형을 가려 등록했다. 매핑 표에는 `잰`·`쟀`·`재어` 만 있다.
아래 넷은 같은 이유로 뺐다. 다시 넣으면 오탐이 난다.

| 뺀 활용형 | 함께 걸리는 말 |
| --- | --- |
| `재는` | 현재는, 존재는, 소재는 |
| `재고` | 재고(inventory) |
| `재면` | 현재면, 부재면 |
| `재야` | 재야(在野) |

등록한 셋으로는 `재색인`·`재현율`·`재시도`·`재고` 가 걸리지 않는 것을 확인했다.

`좁히다` 는 `권한을 좁` 으로 시작하는 구절만 등록했다.
`좁히`·`좁힌`·`좁혀` 만 등록하면 `원인을 좁혀 나간다`, `후보를 좁힌다` 같은 자연스러운 문장과
`외과적` 의 권장어 `범위를 좁힌` 까지 걸린다.

1.17.0 에서는 비유 표현을 산출물에서 쓰지 않기로 해 활용형 전체를 등록했다.
`원인을 좁혀 나간다` 같은 자연스러운 문장도 걸리는 것을 감수한다.
한글 완성형 부분 문자열 검색에서는 `좁히` 가 `좁힌` 을 포함하지 않아 둘 다 등록한다.
형용사 `좁다` 와 그 활용형은 이 규칙의 대상이 아니다.

## 버전 뜻의 구절

1.19.0 에서는 `판` 한 글자 대신 조사나 서술어가 붙은 구절을 등록했다.
권장 표현은 `버전` 이다.

| 등록 구절 | 등록 이유 |
| --- | --- |
| `SDK 판을` / `SDK 판이` / `SDK 판으로` | SDK 버전을 가리키는 문장을 찾는다 |
| `BOM 판을` / `BOM 판이` / `BOM 판으로` | BOM 버전을 가리키는 문장을 찾는다 |
| `같은 판을` / `같은 판이` / `같은 판으로` | 조사까지 포함해 판단·판정과 겹치지 않게 한다 |
| `고정 판을` / `고정 판이` / `고정 판으로` | 조사까지 포함해 판단·판정과 겹치지 않게 한다 |
| `마지막 판을` / `마지막 판이` / `마지막 판으로` | 조사까지 포함해 판단·판정과 겹치지 않게 한다 |
| `지시문 판을` / `지시문 판이` / `지시문 판으로` | 조사까지 포함해 판단·판정과 겹치지 않게 한다 |
| `판을 올` / `판이 바뀌` / `판으로 고정` / `판도 올` | 서술어 일부까지 포함해 판단·판정과 겹치지 않게 한다 |

아래 후보는 그대로 등록하지 않고 조사까지 늘렸다.
부분 문자열 검색은 단어 경계를 구분하지 않으므로 기술 문맥의 접두사만으로도 오탐을 막을 수 없다.

| 뺀 후보 | 함께 걸리는 말 |
| --- | --- |
| `SDK 판` | SDK 판단, SDK 판정 |
| `BOM 판` | BOM 판단, BOM 판정 |
| `같은 판` | 같은 판단, 같은 판정 |
| `고정 판` | 고정 판단, 고정 판정 |
| `마지막 판` | 마지막 판단, 마지막 판정 |
| `지시문 판` | 지시문 판단, 지시문 판정 |

등록 구절은 `판단을 올려`, `판정이 바뀌`, `같은 판정`, `판단으로 고정` 을 잡지 않는다.
조사 없는 표현과 등록하지 않은 활용형은 검사기가 찾지 못하므로 의미 점검에서 확인한다.
