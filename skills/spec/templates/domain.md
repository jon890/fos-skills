# 주문 도메인

## 용어와 개념
| 용어 | 뜻 |
| --- | --- |
| 취소 가능 주문 | 결제가 끝났고 출고가 시작되지 않은 주문 |

## 판단 규칙

### RULE1 주문 취소 가능 기간
| 항목 | 내용 |
| --- | --- |
| 적용 조건 | 결제가 끝났고 출고가 시작되지 않은 일반 주문 |
| 판단 기준 | 결제 승인 시각부터 정한 시간 안이면 취소할 수 있다. 값의 원본은 `config/order-rules.yaml` 의 `cancel_window_hours` 다 |
| 숫자 기준 | 단위는 시간, 측정 시점은 결제 승인 시각, 데이터는 결제 시스템 기록, 대상은 일반 주문 |
| 결측·지연·상충 | 결제 승인 시각이 없으면 취소를 막고 상담으로 넘긴다 |
| 우선순위 | 출고 시작 규칙(RULE2)이 먼저다 |
| 결정 상태 | 확정 |
| 제안자 | 기획 |
| 확정 근거 | 사용자 2026-11-03 |
| 외부 검토 | 해당 없음 |
| 근거 | 기능 스펙의 결정 표 또는 배경을 담은 ADR 경로 |
| 확인 사례 | 결제 23시간 뒤 요청은 취소된다. 25시간 뒤 요청은 거부된다 |
