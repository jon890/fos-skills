# ADR-003: 내보내기 전용 원본을 플러그인 스킬 목록에서 제외한다

- **status**: `accepted`
- **결정**: `content-preview` 와 `korean-check` 를 `.claude-plugin/plugin.json` 의 `skills` 배열에서 제외한다.
  두 디렉터리와 `scripts/export-to-team.sh` 의 내보내기 목록은 그대로 둔다.
  ADR-001 의 루트 배치는 유지하되, 모든 스킬을 목록에 등록한다는 결정만 바꾼다.
- **맥락**: 팀 저장소의 플러그인이 두 스킬의 사본을 싣는다.
  두 플러그인을 함께 설치하면 같은 스킬이 접두사만 다르게 두 번 뜬다.
  원본 파일을 옮기거나 삭제하면 내보내기와 형제 경로 참조가 바뀌므로 목록에서만 제외한다.
  2026-10-01 에 격리 설치 테스트로 스킬 다섯 개만 인식되고 두 원본이 캐시에 남는 것을 확인했다.
  형제 참조, 검사기 탐색과 도구 탐색도 통과했다.
- **결과**:
  - 이 플러그인에는 다섯 스킬이 뜬다.
    두 스킬의 원본은 여기 있고, 스킬로는 사본을 싣는 팀 저장소의 플러그인으로 받는다.
    그 플러그인을 받을 수 없는 환경에서는 두 스킬이 목록에 뜨지 않는다.
  - 설치 캐시에는 원본 디렉터리가 남으므로 파일 경로로 읽거나 스크립트를 실행하는 참조는 유지한다.
    현재 다른 스킬의 참조는 `harness-cleanup/references/audit-axes.md` 의 상대 링크이며, 두 스킬을 이름으로 호출하는 곳은 없다.
  - `scripts/export-only-skills.json` 에 제외할 원본을 명시한다.
    테스트는 이 목록에 없는 스킬이 배열에서 빠지거나 내보내기 전용 원본이 다시 등록되면 실패한다.
  - 플러그인 버전은 ADR-002 를 따라 커밋 SHA 를 사용한다.
    스킬 본문과 스크립트 동작을 바꾸지 않으므로 스킬 버전은 그대로 둔다.
- **적용 범위**: 배치와 테스트는 [code-architecture.md](../code-architecture.md) 가, 설치는 [flow.md](../flow.md) 가 소유한다.
