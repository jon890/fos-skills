# CHANGELOG: work-board

work-board 는 스킬이 아닌 mod 이므로 이 파일에서 변경 이력을 시작한다.
버전 등급과 쓰는 형식은 저장소 README 의 「버전과 변경 이력」 을 따른다.

## 1.0.1 (2026-10-30)

- 질문 payload 가 객체여도 dispatch 와 본문을 읽는다. 끝난 dispatch 의 질문을 결정 필요에서 빼고 재전송 질문은 최신 하나로 묶는다
- worker 목록을 모든 페이지에서 읽고 `pending`, `running` 상태도 진행 중으로 보여 준다

## 1.0.0 (2026-10-28)

- `u` 보드 갱신 버튼이 실제 상태를 대조하고 보드를 고치는 요청문을 입력란에 채운다
- 단계 끝의 `(#665 merge)` 같은 사건 꼬리표를 읽으며, 창에서는 꼬리표를 숨긴다
