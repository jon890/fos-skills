# CHANGELOG: report

버전은 `SKILL.md` frontmatter 의 `metadata.version` 과 같은 값을 쓴다.
올리는 기준과 쓰는 형식은 저장소 README 의 "버전과 변경 이력" 을 따른다.

## 2.1.0 (2026-11-12)

- 처음 읽는 사람이 한 번에 알아듣는 한국어 작성 규칙을 적용하고 의미 점검을 마친 뒤 보고서를 띄운다
- 표기 검사 통과 뒤에도 의미 점검이 남았음을 알리고, 확인한 범위와 반영하지 않은 발견의 이유를 응답에 남긴다

## 2.0.2 (2026-11-06)

- 심볼릭 링크로 부른 진입도 import.meta.main 이 없는 Node 24.0·24.1 에서 일을 하도록 직접 실행 판정을 실체 경로로 비교한다

## 2.0.1 (2026-11-06)

- `--korean` 이 korean-check 의 `check.sh` 대신 `check.ts` 를 node 로 부른다

## 2.0.0 (2026-11-06)

- 호환성: 검사 스크립트를 `check-report.py` 에서 Node 24 의 `check-report.ts` 로 바꿨다. `node "$SKILL_DIR/scripts/check-report.ts"` 로 부른다
- 옵션, 출력, 종료 코드는 그대로다. 이 스킬을 쓰려면 Node 24 이상이 필요하다

## 1.x

- layouts.md 와 겹치는 구성 선택, 본문 규칙 문장을 지우고 재시도 횟수를 한 곳에만 적었다
- 내보내기 전용 원본의 한국어 검사기를 새 배치에서 찾아요.
- 새 스킬. `/report` 나 「HTML 로 시각화해서 설명해 줘」 로 부르면 있는 내용을 HTML 보고서 한 파일로 만들어 기본 브라우저로 띄운다
