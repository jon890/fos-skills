# 자동 갱신 인수 검증

완료: PR 전 인수 검증과 독립 코드 리뷰의 차단 지적 반영. 머지 뒤 실제 설치본 확인은 코디네이터가 맡는다.

- 스펙: [spec.md](spec.md)
- 설계: [design.md](design.md)
- 검증 대상: 이 PR 의 마지막 커밋
- 환경: macOS, Node.js 24.22.1, 임시 Claude 설정 폴더와 가짜 명령 실행기. 리뷰 뒤 루프 테스트의 홈·프로필·상태 폴더도 임시 경로로 고정했다.

## 요구사항별 증거

| 요구사항 | 실행 방법 | 기대 결과 | 실제 결과 |
| --- | --- | --- | --- |
| REQ1 | `plugin-auto-update.spec.ts` 의 버전·설치 기록 사례 | main 이 높을 때만 갱신하고 기록된 version 이 같을 때 성공 | 높은 설치본은 건너뛰고, 명령이 성공해도 기록이 그대로면 실패 처리하고 다음 확인에 재시도했다 |
| REQ2 | 같은 테스트의 홈·Orca 프로필·project·local·캐시 공유 사례 | 각 설정 폴더와 scope 의 설치본을 해당 경로에서 갱신 | 설정 폴더와 프로젝트 작업 경로가 예상값과 같았다. 다른 프로필의 캐시를 가리키는 기록도 처리했다 |
| REQ3 | 같은 테스트의 작업 폴더 설치 사례 | 개발용 폴더에서 갱신과 git 명령을 실행하지 않음 | 대상 캐시 설치본이 없으면 main 조회를 포함한 외부 명령을 실행하지 않았다 |
| REQ4 | 같은 테스트의 30분 경계·잠금·재확인 사례 | 잠금 중에는 건너뛰고, 성공한 버전은 재설치하지 않으며 실패는 재시도 | 잠금 중 추가 확인이 없었고, 30분 경계에서 성공 결과만 유지했다. 실패한 설치본은 다시 시도했다 |
| REQ5 | `plugin-auto-update.spec.ts`, `plugin-auto-update-loop.spec.ts`, `loop-self-update.spec.ts` | 설치 결과를 다시 뜨기 알림에 붙이고 실패는 버전당 한 번 알림 | 실패 알림 전달과 같은 버전의 다시 뜨기 알림 꼬리를 테스트했다. 실제 Orca 알림 수신은 머지 뒤 확인한다 |
| REQ6 | `version.spec.ts` 와 `network-poll.spec.ts` | 새 설치본을 먼저 표시하고 내장 명령을 세션이 쉴 때 한 번 예약 | 내장 `reload-plugins` 만 실행하고 같은 버전의 중복 예약을 막았다. 명령이 없거나 실패하면 `p` 안내와 버튼으로 돌아간다 |
| REQ7 | `plugin-auto-update-loop.spec.ts` 와 설정 스키마 테스트 | `plugin.auto_update` 는 참거짓만 받고 false 일 때 루프가 갱신을 건너뜀 | false 면 갱신 함수를 부르지 않고 문자열 값은 거부하는 것을 테스트했다 |

전체 저장소 검증 `orch slot heavy --exclusive -- node scripts/run-tests.ts` 는 테스트 파일과 타입 검사를 모두 통과했다. `claude plugin test .`, `node scripts/check-skill-docs.ts`, 한국어 변경 줄 검사도 통과했다.

## 독립 검토와 남은 확인

독립 코드 리뷰에서 실제 설정 폴더에 닿을 수 있는 기존 루프 테스트와 다시 읽기 실패 시 수동 갱신 안내가 사라지는 문제를 찾았다. 루프 테스트 환경을 임시 폴더로 고정하고, 자동 다시 읽기에 실패하면 `p` 버튼을 되살렸다. 머지 뒤 실제 새 버전으로 자동 갱신하고 세션이 쉴 때 다시 읽는 확인은 코디네이터가 맡는다.

리뷰 중 2026-11-20 06:05 UTC 에 이 머신의 user 범위 설치본이 갱신된 사실이 확인됐다. 이 worker 의 앞선 전체 테스트와 커밋은 PR 생성 시각인 05:49 UTC 전에 끝났다. 실제 자동 갱신 상태 파일의 마지막 수정 시각은 05:21 UTC 이므로 06:05 설치본 갱신과 시각이 다르다. 당시 테스트가 실제 설정 폴더와 상태 파일을 참조할 수 있었던 결함은 있었으며, 설치본 갱신 원인은 확인되지 않았다. 리뷰 뒤 실행한 테스트는 실제 설정 폴더와 상태 파일을 읽거나 갱신하지 않도록 임시 홈·프로필·상태 폴더를 주입했다.
