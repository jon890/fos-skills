## 1.31.0

생기다, 만들어지다, 표시되다를 `서다` 로 비유한 말투 `카드가 선다`, `티켓이 서지 않는다` 를 금지어로 막는다.

- 매핑 표에 `이 선다`, `가 선다`, `이 서야`, `가 서야`, `이 서지 않`, `가 서지 않` 을 더했다. 권장 표현은 `만들어진다`, `생긴다`, `표시된다` 다
- `서지` 만 등록하면 書誌 뜻의 `이 서지 정보` 가 걸려 `서지 않` 까지 붙였다. 줄이 서는 뜻의 `줄이 선다`, `줄이 서야` 는 `COMPOUND_ALLOW` 에 뒀다
- 막는 표본과 `순서`, `서지 정보`, `서버`, `줄이 선다` 같은 통과 표본을 테스트에 더하고, 등록 형태와 이유를 `checker-maintenance.md` 에 적었다

- `여기서는 화면`, `문서는 곳곳에` 가 걸리지 않도록 `WORD_START_PREFIXES` 에 `서` 를 더했다. `서` 로 시작하는 다른 금지어는 없다
- 막는 표본과 통과하는 표본을 테스트에 더하고, 등록 형태와 이유를 `checker-maintenance.md` 에 적었다

- 표 이름을 「어색한 말 매핑 표」 로 바꾸고 33줄을 12줄로 줄였다. 평범한 우리말(`좁히다`, `가르다`, `덮다`, `재다`, 버전 뜻의 `판` 등)과 남길지 애매한 줄, 영어 원어 줄을 뺐다.

- 「용어를 옮기지 않는다」 에 영어로 두는 개발 용어 목록을 두었다.
- 가독성 검사기의 저장소 전수 테스트를 지웠다. 금지어 저장소 테스트는 유지한다.

## 1.18.0

`korean-style.md` 와 `writing-structure.md` 는 rules 심링크로 매 세션 실려 두 파일이 12.5KB 였다.
1.9.0 에서 두 파일을 채팅 답변에도 적용하려고 그대로 두었다. 이 판단은 유지한다.
다만 매 답변에 필요한 것은 규칙이고, 예시 표와 실측 사례는 문서를 쓰거나 검토할 때만 필요하다.

그래서 `korean-style.md` 에는 매 답변에 적용하는 핵심만 남겼다.
외래어 매핑 표는 제목과 위치, 내용을 그대로 두어 검사기 동작이 같다.
옮긴 것은 아래와 같다.

| 내용 | 전 | 후 |
| --- | --- | --- |
| 「문장 구성」 의 고칠 문장 표 | `korean-style.md` | `korean-examples.md` 「문장 구성」 |
| 「고쳐 쓴 예시」 네 표 | `korean-style.md` | `korean-examples.md` 「고쳐 쓴 예시」 |
| 실측으로 되돌린 사례 표 | `korean-style.md` | `korean-examples.md` 「실측으로 되돌린 사례」 |
| 「짧은 글에서 하지 않는 것」 | `writing-structure.md` | `korean-style.md` |

옮긴 자리에는 읽을 때와 경로만 남겼다.
짧은 글인지 판정하는 「분량 구간」 은 `writing-structure.md` 에 그대로 있다.

`README.md` 의 설치 블록은 rules 에 `korean-style.md` 하나만 건다.
그대로 두면 다음 설치가 `writing-structure.md` 심링크를 되살린다.
`review-axes.md` 와 `SKILL.md` 의 참조도 새 위치로 고쳤다.

심링크로 걸어 두고 부르는 것이 기본 사용법이라 `$0` 을 실체까지 따라간다.

매핑 표를 찾지 못하면 종료 코드 2 로 끝낸다.
전에는 0 으로 끝나 검사기가 돌지 않은 것이 통과로 보였다.

검사기 둘을 함께 돌리는 `scripts/check.sh` 를 더했다.
따로 부르면 앞의 것이 실패해도 뒤의 것이 그대로 돌아,
호출한 쪽이 종료 코드를 하나만 읽고 통과로 판단한다.

**검사기가 돌지 않은 것이 통과로 보이는 경로 넷을 검토에서 찾아 막았다.**
넷 다 실행으로 재현했다.

| 무엇 | 어떻게 보였나 |
| --- | --- |
| 종료 코드를 뒤에 돈 검사기가 덮었다 | 매핑 표를 찾지 못한 2 가 1 로 내려와 위반 하나만 고치게 됐다 |
| 없는 경로를 인자로 받았다 | 검사기 둘이 각각 건너뛰고 「통과: 2개 파일」 을 내며 0 으로 끝났다 |
| 확장자가 `.md` 가 아니었다 | 금지어 검사기만 건너뛰어 같은 내용이 `.txt` 에서는 통과로 나왔다 |
| 임시 디렉터리 생성이 실패했다 | 빈 경로에 쓰다 실패한 뒤에도 검사기를 불러 0 으로 끝났다 |

종료 코드는 둘 중 큰 값을 내고, 대상이 없거나 확장자가 다르면 2 로 끝낸다.
`mktemp` 템플릿의 `X` 를 명시했다. `-t` 에 접두사만 주면 GNU coreutils 가 거부한다.

검토자에게 주는 기준을 `references/review-axes.md` 로 만들었다.
`content-preview` 의 자가 점검 목록에 있던 다섯 축이 출발점이고,
실측에서 검토자가 잡은 본문 내부 모순과 지어낸 번역어를 더했다.
반영 전에 검토자가 든 사실을 확인하는 조건도 통과 조건에 넣었다.
