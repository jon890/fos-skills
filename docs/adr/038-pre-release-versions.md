# ADR-038: 외부 공개 전 플러그인과 스킬의 버전을 0.x로 관리한다

- **status**: `accepted`
- **decision-type**: `engineering-process`
- **현재 규칙의 원본**: [버전과 변경 이력](../contributing.md#버전과-변경-이력), [설치본 갱신](../flow.md#갱신)
- **결정**: 플러그인은 `0.21.0`에서 시작한다. 스킬은 `X.Y.Z`에서 `0.(X+1).0`으로 옮기고 이전 버전 절을 보존한다. 새 기능과 호환성 변경은 minor, 나머지는 patch로 올리며 첫 `1.0.0`은 외부 공개 때 사람이 정한다. 사용자 결정 2026-11-26.
- **대체 관계**: [ADR-019](019-plugin-version-auto-bump.md)의 시작 번호와 자동 올림 등급, [ADR-023](023-version-at-merge.md)의 호환성 변경 등급과 기록 방식을 대체한다.
- **맥락**: 팀 내부에서 먼저 사용하며 개선하고 있어 공개 버전처럼 보이는 번호 대신 준비 단계가 드러나는 번호가 필요하다. Claude Code 2.1.332에서 임시 마켓플레이스의 `20.10.1`을 `0.21.0`으로 갱신했다. 두 캐시 폴더가 남았고 설치 기록은 `0.21.0`을 가리켰다.
- **대안 기각**: 기존 major를 계속 올리면 이미 공개한 버전의 호환성 계약으로 읽힐 수 있다.
- **결과**
  - 새 번호로 공개 준비 단계를 드러내면서 변경 이력을 계속 읽을 수 있다. 호환성이 달라지는 변경도 머지할 때 조각으로 처리할 수 있다.
  - 실행 중인 옛 루프의 첫 전환은 수동 갱신으로 시작한다. `1.0.0`을 다시 쓰기 전에 옛 캐시와 버전 비교의 전환 규칙을 정리한다.
