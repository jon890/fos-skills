# CHANGELOG: pr-review

버전은 `SKILL.md` frontmatter 의 `metadata.version` 과 같은 값을 쓴다.
올리는 기준과 쓰는 형식은 저장소 README 의 "버전과 변경 이력" 을 따른다.

## 2.0.1 (2026-11-06)

- 심볼릭 링크로 부른 진입도 import.meta.main 이 없는 Node 24.0·24.1 에서 일을 하도록 직접 실행 판정을 실체 경로로 비교한다

## 2.0.0 (2026-11-06)

- 호환성: 스크립트 넷을 `.sh`, `.py` 에서 Node 24 의 `.ts` 로 바꿨다. `node "$SKILL_DIR/scripts/gh-review-post.ts"` 처럼 이름의 확장자만 바꿔 부른다
- 옵션, 출력, 종료 코드는 그대로다. 이 스킬을 쓰려면 Node 24 이상이 필요하다

## 1.x

- 미리보기 단계에서 content-preview 가 소유한 절차를 다시 적은 문장과 중복 규칙을 지우고 질문형 제목을 고쳤다
- 문서 블록의 `<자리표시자>` 를 변수로 바꿔 bash 와 zsh 에서 문법 오류 없이 돈다
- 문서 표현만 고쳤다. 동작은 바뀌지 않았다
- dispatch 로 받은 세션은 미리보기를 띄우고 턴을 끝낼 수 없으므로, 4단계 통과 조건을 `preview.html` 생성과 보고에 적은 경로로 뒀다. `content-preview` 의 「보는 사람이 없는 세션에서 등록할 때」 를 따른다
- README 를 스킬을 쓰는 사람 관점으로 다시 쓰고, 이 CHANGELOG 를 버전마다 핵심만 남기도록 줄였다. 동작은 바뀌지 않았다
- korean-check 금지어에 걸린 문구를 권장 표현으로 바꿨다. 동작은 바뀌지 않았다
- 다른 PR 과 이슈는 백틱 없이 `#102`, 다른 저장소면 `owner/repo#102` 로 쓴다
- `SKILL.md` 에 목표 문장과, 단계마다 통과 조건을 담은 개요 표를 더했다
