# orch: 저장소마다 메인 코디네이터 하나를 두고, 다른 코디네이터는 메인에게 요청만 보낸다

확인: 2026-11-17

## 목표

저장소 하나의 worker 띄우기, 지시, 머지, 정리, 보드 쓰기를 그 저장소의 메인 코디네이터 하나가 맡는다.
다른 저장소나 같은 저장소의 다른 세션은 그 메인에게 요청을 보내고, 메인의 하위 worker 를 직접 띄우거나 지시하지 않는다.
메인끼리는 요청 번호가 붙은 요청과 완료 알림으로 주고받는다.

- 배경: 2026-11-17 PR 517 의 worker 는 ai-analysis 의 메인(`run_2e612cc5f0ca`)이 fos-skills 에 직접 띄운 것이었다. fos-skills 에는 따로 메인(`run_96936710a9fc`)이 있었다.
  fos-skills 쪽에는 이 PR 을 맡은 코디네이터가 없어, 다른 세션이 띄우기 기록에서 Run 을 찾아 `--run` 을 붙여 머지했다. 정리 때 fos-skills 루프는 남의 Run 상태 파일을 「Run 을 알 수 없다」 로 남겼다.
- 같은 날 fos-skills 루프는 터미널이 이미 없는 옛 메인 Run 에 묶여 있어서, 새 세션이 `orch loop start` 를 하면 `LOOP-START-FENCED` 로 막혔다. 코디네이터가 `orch loop stop --run <옛 Run>` 으로 옛 Run 을 직접 빼야 했다.
- `send-to-worker.ts` 는 다른 Run 의 worker 에게 보낼 때 보내는 쪽 표시(`--from`)를 빼서 Orca 의 Run 경계 검사(`dispatch_run_mismatch`)를 피해 간다(머리 주석 14~16줄).
- 메인끼리 이야기할 길은 이미 있다. 루프 알림은 `orca orchestration send --to run:<Run>` 으로 코디네이터에게 가고 Orca 가 받는 쪽을 깨운다(`skills/orch/scripts/lib/run-notice.ts`, [ADR-027](../../adr/027-orca-message-wake.md)).

## 범위

이번 범위:

- 저장소의 메인 판별과 메인 교대
- 메인에게 보내는 요청 명령, 요청 번호, 받음·완료·거절·보류 알림, 양쪽 보드 항목, 답 없음 알림
- 메인이 아닌 세션의 orch 쓰기 명령 거절과 명시적 우회 옵션
- 한 저장소에 코디네이터 세션 여럿이 루프 하나를 함께 쓰던 동작([ADR-012](../../adr/superseded/012-orch-loop-multi-run.md))을 메인 하나로 바꾸는 것

범위 밖:

- orch 를 거치지 않는 직접 조작(`gh pr merge`, `git push` 를 코디네이터가 직접 부르는 것). orch 가 막을 수 없다
- 메인이 없는 저장소에 worker 를 띄우는 동작. 지금처럼 그대로 둔다(DECISION1)
- 배포 시점에 이미 떠 있는 worker, 메인이 없을 때 다른 저장소에서 띄운 worker 를 옮기는 일. 띄운 메인이 끝까지 맡는다(DECISION11, DECISION25)

PR 순서: PR1 은 메인 판별, 메인 교대와 넘겨받기, 요청 명령과 알림, 보드 항목이다. PR2 는 메인이 아닌 세션의 쓰기 명령 거절과 우회 옵션이다(DECISION9).

| DECISION26 | 같은 Run 에 묶인 다른 터미널 | 메인으로 본다 | 작성자 | 막는 기준이 Run 이라 같은 Run 은 같은 메인이다(DECISION23) |
| DECISION16 | 메인 판별 근거 | 저장소 루프에 등록된 Run 과 Orca 의 Run 코디네이터 터미널(`run-list` 의 `coordinator_handle`)에서 에이전트가 실행 중인지(DECISION19) | 작성자 | Orca 의 Run 에는 저장소 정보가 없고, 루프 등록은 저장소마다 있다(`state/loop-runs/`) |
| DECISION17 | 메인 사이 메시지 경로 | 기존 `orca orchestration send --to run:<Run>` | 작성자 | 루프 알림이 이미 쓰고 Orca 가 받는 쪽을 깨운다([ADR-027](../../adr/027-orca-message-wake.md)) |
