- 기능 PR 의 `후속 검증: 대기` 를 마무리가 저장소별 배포 뒤 할 일 목록으로 옮긴다. `orch status`, `orch followup list`, 보드의 `followup-<PR>` 항목에서 보인다.
- 후속 검증이 끝날 때까지 워크트리, 지시서, 그 PR 의 handoff 산출물은 남기고 마무리의 실패로 세지 않는다.
- 상주 루프가 배포를 확인하면 배포 뒤 할 일을 `FOLLOWUP-READY` 로 한 번 묶어 알리고, `orch followup done <PR>` 이 항목을 끝낸 뒤 마무리를 다시 띄워 남긴 워크트리 정리, 업무 완료, 보드 done 까지 간다.
