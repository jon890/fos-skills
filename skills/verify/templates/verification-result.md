# 인수 검증 결과

필수 칸을 실제 실행 결과로 채운다. 예시·빈칸을 통과 증거로 사용하지 않는다. 결과는 PR 본문 또는 PR 별 증거 파일에 남긴다. -->

- 판정: 완료 또는 미완료와 돌아갈 단계
- 스펙 / 기술 설계 / 계획 / 검증 계획: 각 경로
- 검증 커밋: 실제 SHA
- 환경: 실행 환경·버전·필요한 테스트 데이터

## 요구사항별 증거

| 요구사항 | 사례·실행 명령 또는 절차 | 기대 결과 | 실제 결과·증거 위치 | 판정 |
| --- | --- | --- | --- | --- |
| REQ1 | 격리 API 에 다른 사용자 취소 요청 후 DB 조회 | 거부·저장 상태 유지 | 실제 응답·상태와 로그 위치를 기록 | 통과 / 실패 / 미실행 |

## 독립 검토

코드·문서 검토자와 결과, 남은 발견. 오버레이가 PR 자동 리뷰에 맡긴 경우 아직 받은 결과와 대기 항목을 구분한다.

## 남은 검증과 기능 전체

PR 전 필수 미검증, 머지·배포 뒤 검증과 선행 조건, 담당 단계. 없으면 없음.
이번 PR 의 부분 검증 통과와 기능 전체 완료를 구분한다. 실행하지 못한 사례는 통과로 쓰지 않는다.

## 변경한 결정 대조 (해당할 때만)

| 결정 기록·종류 | 현재 규칙의 원본 | 구현·설정·사례 증거 | 대체 관계·판정 |
| --- | --- | --- | --- |
| 변경한 ADR 과 decision-type | 관련 문서·규칙 ID 또는 코드·설정 | 실제 확인한 경로와 실행 근거 | 정합 / 실패 / 미실행, 새 결정은 반환할 단계 |

기존 ADR 의 타입 누락만으로 실패시키지 않는다. 대체된 기록의 당시 맥락을 현재 구현에 맞춰 다시 쓰지 않는다.
