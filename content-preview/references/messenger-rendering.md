# Dooray 메신저 렌더 확인 범위

`--mode messenger` 는 `--title` 을 대화방 이름, `--author` 를 보내는 사람으로 표시한다.
업무·댓글의 TOAST UI viewer 를 본문에 적용하지 않는다.

## 확인한 것과 미확인 항목

2026-10-07 에 `dooray messenger channels --json` 과 선택한 대화방의
`dooray messenger logs "$CHANNEL_ID" -n 400 --json` 을 읽었다.
195건이 반환됐다. 원문에 표기가 있다는 사실만으로 화면에서 렌더된다고 판정하지 않는다.
원문과 사내 식별자는 공개 저장소에 보관하지 않는다.

| 형식 | 확인 상태 | 근거 | 미리보기 처리 |
| --- | --- | --- | --- |
| `[@example](dooray://example/members/example "member")` | 확인 | 화면 실측(2026-10-07), 조회 원문 31건 | 멘션 링크 |
| HTTPS 주소 | 확인 | 화면 실측(2026-10-07), 조회 원문 8건 | 주소 그대로 링크 |
| `dooray://` 업무 마크다운 링크 | 확인: 링크로 렌더되지 않음 | 화면 실측(2026-10-07), 조회 원문 1건 | 원문과 경고 |
| `dooray://` 위키 마크다운 링크 | 미확인 | 조회 원문에서 확인하지 못함 | 원문과 경고. 업무 링크와 같은 위험을 알림 |
| 굵게·제목·표·목록 | 확인: 렌더되지 않음 | 사용자 실측(2026-11-02). 기호가 그대로 보였다 | 원문과 경고 |
| 코드 블록 | 확인: 렌더되지 않음 | 사용자 실측(2026-11-02). 백틱이 그대로 보였다 | 원문과 경고 |
| 인라인 코드 | 확인: 렌더됨 | 사용자 실측(2026-11-02) | 코드 모양 |
| `[제목](https://...)` 일반 마크다운 링크 | 확인: 렌더됨 | 사용자 실측(2026-11-02) | 제목을 링크로 |
| 취소선 | 미확인 | 화면 렌더 결과를 확인하지 못함 | 원문 |
| 번호 목록(`1.`) | 평문으로 보임 | 사용자 실측(2026-11-02). 목록 대신 쓰는 형식이다 | 원문 |

줄바꿈과 공백은 보존하고 HTML 은 문자로 표시한다.
업무·위키 링크와 렌더되지 않는 형식의 경고는 HTML 맨 위와 stderr 에 같은 문구로 나온다.
형식 경고는 찾은 형식의 이름과 대신 쓸 형식을 알린다. 항목은 「1.」 같은 평문 번호와 빈 줄로 나누고, 표는 「항목: 값」 처럼 한 줄씩 쓴다.
코드 블록과 인라인 코드 안의 기호는 형식 판정에서 뺀다.
기본 종료 코드는 0 이며, `--strict` 를 주면 경고가 있을 때 HTML 을 만든 뒤 1 로 끝난다.
