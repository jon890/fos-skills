# plan 하나는 PR 하나다

**plan 하나는 PR 하나로 끝나는 크기로 자른다. 대략 하루 안에 구현하고 머지까지 가는 일이다.**
더 큰 일은 plan 을 여럿으로 나누고, 지금 할 plan 만 자세히 쓴다.
뒤의 일은 목표 표나 그 저장소의 할 일 목록에 한 줄로 두고, 앞 PR 이 머지된 뒤 그때의 코드를 보고 계획한다.

## 이유

미리 써 둔 phase 문서는 앞 phase 를 하는 사이 낡는다.
크기가 크면 구현자가 draft PR 에서 멈추고, CI 실패와 충돌이 날 때마다 다시 맡겨야 한다.

## 어디서 판단하나

| 단계 | 판단 |
| --- | --- |
| 3 PR 범위 | 「이 변경이 어디까지 손대나」 에서 이번 PR 의 범위를 한 문장으로 정한다. 이 문장이 `index.json` 의 `pr_scope` 가 된다 |
| 4 task 작성 | phase 로 나누기 전에 범위가 PR 하나에 들어가는지 본다. 넘으면 plan 을 나누고 지금 할 것만 phase 로 쓴다. 뒤로 미룬 일은 `deferred` 에 적는다 |

PR 순서와 단위처럼 사용자가 정할 것은 spec 인터뷰가 묻고 스펙에 닫혀 있다. plan 은 그 결정을 따라 이번 PR 하나의 범위를 자른다.
스펙이 정한 단위가 아래 「검사 기준」 의 크기를 넘어 더 나눠야 할 때만 plan 이 사용자에게 어디서 자를지 묻는다. 앞 plan 이 끝나야 의미가 생기는 선을 고른다.

## 뒤로 미룬 일

뒤의 plan 은 phase 문서를 쓰지 않는다. 한 줄로 아래 세 가지만 남긴다.

| 칸 | 담는 것 |
| --- | --- |
| `what` | 무엇을 하나 |
| `why` | 왜 지금 이 plan 에 넣지 않나 |
| `after` | 앞 plan 의 무엇이 머지된 뒤에 하나 |

한 줄은 `index.json` 의 `deferred` 에 적고, 저장소에 목표 표나 할 일 목록이 있으면 거기에도 옮긴다.
`deferred` 가 가리키는 일은 그 PR 이 머지된 뒤 `plan` 을 다시 열어 계획한다.
`orch` 로 구현을 맡길 때 plan 하나는 worker 하나다. 뒤 plan 은 앞 PR 이 머지된 뒤 코디네이터가 새 지시서로 새 worker 에게 맡기고, 앞 worker 가 이어 맡지 않는다.

## 검사 기준

`verify_task.ts` 가 아래를 본다.

| 검사 | 결과 |
| --- | --- |
| phase 가 6개를 넘는다 | 위반. plan 을 나눈다 |
| 변경 파일이 40개를 넘는다 | 경고. 디렉터리 이동 같은 일괄 이동이면 `pr_scope` 에 그렇게 적는다 |
| 레포 설정의 「PR 변경 파일 상한」 을 넘는다 | 경고. 40개 기준 대신 쓰고, phase 별 변경 파일 수를 함께 내 나눌 선을 고르게 한다 |
| 수정할 파일이 레포 설정의 「파일 길이 상한」 의 95% 이상이다 | 경고. 더할 코드를 새 파일로 나눌지 계획에서 정한다 |
| `pr_scope` 가 비었거나 한 문장이 아니다 | 위반 |
| `deferred` 칸이 없거나, 항목에 `what`, `why`, `after` 가 비었다 | 위반. 미룬 일이 없으면 빈 배열이다 |

레포 설정 값의 이름과 형식은 [레포 설정 탐색](monorepo.md#스크립트가-직접-읽는-값)이 정한다.
저장소의 크기 기준은 구현 뒤 PR 크기 측정에서야 걸리면 phase 커밋을 옮기고 계획을 다시 써야 해서, 계획 단계에서 같은 기준으로 본다.

`created_at` 이 2026-10-25 보다 이르거나 없는 옛 plan 은 같은 검사를 경고로만 낸다. 진행 중인 계획서를 다시 쓰게 하지 않는다.

줄 수 추정은 수정 파일은 작은 변경의 오탐을 줄이려 현재 줄의 20%를, 삭제 파일은 전체 줄을 더하고 신규 파일은 미상으로 두며, `.github/pr-size.json` 이 있으면 그 분류와 등급 기준을 적용한다.

`.github/pr-size.json` 의 `grades` 는 A·B·D 상한을 읽는다. A 이하면 A, A 초과는 B, B 초과는 C, D 초과는 D 이며 각 등급의 어느 항목이든 넘으면 그 기준을 넘은 것이다.
