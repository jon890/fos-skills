# 보고서 구성

넘겨받은 내용의 종류를 보고 세 구성 가운데 하나를 고른다.
구성은 절 순서와 쓰는 부품만 정한다. 모양은 `assets/template.html` 의 CSS 와 부품이 소유한다.

## 고르는 기준

| 내용 | 구성 |
| --- | --- |
| 여러 자료를 조사해 알아낸 사실과 판단 | 조사 보고서 |
| 개념이나 동작 방식 하나를 이해시키려는 글 | 개념 설명 |
| 선택지 둘 이상을 놓고 하나를 고르려는 자료 | 비교·결정 자료 |

**애매하면 묻지 않고 가장 가까운 구성을 고른다.** 다시 요청하면 바로 바뀌므로 기다리게 하는 비용이 더 크다.
고른 구성은 응답에 한 줄로 알린다. 예: `구성: 비교·결정 자료(선택지 셋을 놓고 고르는 내용이라서)`.
선택지와 권장안이 있으면 비교·결정 자료, 그렇지 않고 출처가 여럿이면 조사 보고서, 나머지는 개념 설명으로 본다.

## 모든 구성에 공통인 규칙

- **결론이 첫 화면에 있다.** 머리의 한 줄 요약(`.lead`)에 답을 쓰고, 첫 절을 결론 카드로 둔다.
- 단락은 2~3문장이다. 길어지면 나누거나 표, 목록으로 바꾼다.
- 둘 이상을 비교하면 표로 쓴다. 상태는 칩(예, 일부, 아니오, 미확인)으로 보인다.
- 원문이 길면 본문에는 줄인 글과 표만 두고, 원문의 상세는 접는 절(`details`)에 빠짐없이 옮긴다. 줄이면서 버린 내용이 없어야 한다.
- 원문의 사실, 수치, 날짜, 출처, 「추정」 표시는 바꾸지 않는다. 추정은 `<span class="tag">추정</span>` 으로 단다.
- 출처는 맨 끝의 접힌 출처 표에 두고, 본문에서는 `<a class="ref" href="#src-표시">[표시]</a>` 로 가리킨다. 출처가 없는 내용이면 출처 절과 머리의 `.note` 를 지운다.
- 절 번호(`h2 .no`)와 목차(`nav.toc`)는 실제 절 순서와 맞춘다.

## 한국어로 채우기

3단계에서 본문을 채울 때 아래 규칙을 적용한다. 어휘·문장·구조의 판단 기준과 고쳐 쓴 예시는 korean-check 스킬의 참조 문서가 소유한다.
4단계 의미 점검에서는 그 스킬의 `references/review-axes.md` 를 읽는다.

- **문장 하나에는 뜻 하나만 담는다.** 서로 다른 조치나 이유는 문장을 나눈다.
- **결론을 먼저 쓴다.** 무엇이 어떻게 달라지는지 먼저 말하고 이유와 근거를 뒤에 붙인다.
- 문서나 코드에서만 쓰던 낱말은 평소 쓰는 말로 바꾼다. 독자가 문맥을 짐작해야 뜻이 통하는 표현도 풀어 쓴다.
- 설명에 영어 낱말을 섞지 않는다. 고유명사와 식별자는 원문 표기를 유지하고, 뜻을 설명하는 문장은 한국어로 쓴다.
- 표의 칸은 짧은 명사구로 쓴다. 조건이나 이유가 길면 표 밖에서 설명한다.
- 숫자에는 단위와 비교 대상을 함께 쓴다. 원문에 빠진 단위나 비교 기준은 지어내지 않고 「확인하지 못한 것」 에 남긴다.

쉽게 고치는 대상은 설명 문장이다. 원문 그대로 보존할 인용문, 코드·식별자, 고유명사와 출처 제목은 바꾸지 않는다.

## 조사 보고서

여러 자료에서 알아낸 것을 판단과 함께 보여 준다.

| 절 | 쓰는 부품 | 담는 것 |
| --- | --- | --- |
| 핵심 결론 | 결론 카드 | 조사로 답한 질문마다 카드 하나 |
| 한눈 비교 | 비교표, 칩, 범례 | 조사 대상을 같은 축으로 비교한 표 |
| 항목별 상세 | 접는 절, 모두 펼치기 | 대상마다 접는 절 하나. 원문의 상세를 모두 |
| 확인하지 못한 것 | `ul.plain` | 원문이 답하지 못한 질문 |
| 출처 | 출처 표 | 본문이 가리킨 자료 |

필요하면 한눈 비교 뒤에 강조 상자나 용어 상자를 더한다.

## 개념 설명

개념 하나를 처음 보는 사람이 이해하게 만든다.

| 절 | 쓰는 부품 | 담는 것 |
| --- | --- | --- |
| 한 줄 결론 | 결론 카드 | 무엇이고 왜 쓰는지 |
| 동작 단계 | 단계 목록 | 실제로 일어나는 순서 |
| 비유 | 용어 상자 | 낯선 용어를 백엔드 개념에 빗댄 것 |
| 주의할 점 | 강조 상자 | 잘못 쓰기 쉬운 곳 |
| 상세 | 접는 절 | 원문의 나머지 설명, 예시, 수치 |
| 출처 | 출처 표 | 출처가 있을 때만 |

## 비교·결정 자료

선택지를 놓고 무엇을 고를지 정하게 돕는다.

| 절 | 쓰는 부품 | 담는 것 |
| --- | --- | --- |
| 권장안 | 결론 카드 | 고른 안과 그 이유. 결정이 아직이면 「권장」 으로 쓴다 |
| 선택지 비교 | 비교표, 칩, 범례, `tr.pick` | 선택지를 같은 기준으로 비교한 표. 권장안 줄에 `tr.pick` |
| 선택지별 상세 | 접는 절, 모두 펼치기 | 선택지마다 장점, 단점, 근거 |
| 결정 기준 | 단계 목록 또는 강조 상자 | 무엇을 보고 골랐는지, 고른 뒤 할 일 |
| 남은 질문 | `ul.plain` | 결정 전에 확인할 것 |
| 출처 | 출처 표 | 출처가 있을 때만 |

`assets/template.html` 의 예시가 이 구성이다.
