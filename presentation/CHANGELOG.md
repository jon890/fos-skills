# presentation 변경 이력

## 1.1.0

리뷰에서 나온 것을 고쳤다.

- **금지어를 사본으로 들지 않고 전역 매핑 표를 읽는다.**
  단일 소스는 `~/.claude/rules/korean-style.md` 의 「외래어 매핑 표」다.
  사본은 이미 갈라져 있었다. 「되돌린 사례」 표의 `정점` 을 금지어로 잘못 옮겨
  `수정점검` 과 `그래프의 정점` 이 걸렸고, 매핑 표의 `ingest`·`ramp`·`강등` 은 빠져 있었다.
  전역 검사기와 같은 `게이트웨이` 예외도 함께 둔다.
- **`<style>` 과 `<script>` 를 금지어 검사에서 뺀다.**
  코드라 CSS 의 `baseline` 과 `clamp()` 이 걸렸다. 골격 템플릿 자신이 걸리는 상태였다.
- **브라우저 검사가 실패하면 위반으로 낸다.** 실패해도 마지막 줄이 `통과` 로 끝나
  종료 코드로 둘을 가를 수 없었다. 예외로 빠져나가도 탭을 닫는다.
- **노트 누락을 위반으로 올렸다.** 독스트링이 검사 항목으로 적어 두고 통과시켰다.
- **장을 세는 정규식이 속성 순서를 고정하지 않는다.**
  `data-title` 이 `class` 보다 앞에 오면 장이 0개로 세어져 엉뚱한 지적으로 나왔다.
- **스크립트와 템플릿 경로를 절대 경로로 적는다.**
  덱은 저장소 밖에서 만들므로 상대 경로는 그 디렉터리를 가리켜 없는 파일이 된다.
- **`<title>` 과 `<link>`, 본 `<style>` 을 `<head>` 로 옮겼다.**
  `</head>` 뒤 `<body>` 안에 있었다. 템플릿을 복사해 쓰는 사람이 그대로 물려받는다.
- 「외부 의존이 없다」를 사실에 맞게 고쳤다. 글꼴을 Google Fonts 에서 받는다.
  망 없는 발표장에서 화면이 달라지므로 발표 전에 확인하라는 지시를 넣었다.
- 템플릿 줄 수를 실측값으로 고쳤다. 2,000줄이 아니라 1,300줄대다.
- `evaluation/score.sh` 의 기본 목록에 `presentation` 을 넣고, 끊긴 참조 검사가
  `assets/` 도 보게 했다.

## 1.0.0 (2026-08-31)

첫 버전. 랩 세미나 발표 자료 한 건을 만들면서 겪은 것을 규칙으로 옮겼다.

- `SKILL.md` — 인터뷰 여섯 항목, 파일 규칙, 만드는 순서, 고칠 때의 원칙, 시간 재는 법
- `references/slide-rules.md` — 내용·형태·제목·프롬프트·AI 노출·부 전환·반복 실수·어휘·말 아홉 갈래 판정 규칙
- `references/deck-mechanics.md` — 조작키, 컴포넌트, 재현 애니메이션, 편집 함정
- `assets/deck-template.html` — 골격 한 파일. 예시 장 8개
- `scripts/check-deck.py` — 장 수와 주석 번호, active 장, JS 문법, 하드코딩 잔재, 금지어, 세로 넘침

원본 기준 문서를 옮기면서 고친 것이다.

| 무엇 | 조치 |
| --- | --- |
| 「장 셋으로 압축한다」 아래에 「두 장 각각에」 가 남아 있었다 | 발표 고유 장 구성이라 스킬에서 뺐다 |
| 「두 단계로 보여 준다」 뒤에 세 가지를 나열했다 | 「대화로 보여 준다」 로 고쳐 프롬프트 절에 넣었다 |
| 「회귀 캡처는 지표 다음에 온다」 가 실제 장 순서와 달랐다 | 발표 고유 순서라 뺐다 |
| 「원문은 세션 기록에서 뽑아 쓴다」 | `~/.claude/history.jsonl` 로 고쳤다. 세션 기록에는 최근 것만 남는다 |
| 「데모는 하지 않는다 (미정)」 | 인터뷰 항목으로 옮겼다. 발표마다 정한다 |
| 확정된 장 목록, 결정 현황 | 발표 고유 상태라 뺐다. 확정 장을 고치지 않는다는 규칙만 남겼다 |
| `정점`, `되돌이` 등 전역 매핑 표와 겹친 어휘 | 전역 `korean-style.md` 를 가리키고 발표 고유 금지어만 남겼다 |
