# docs-check 변경 이력

버전은 `SKILL.md` frontmatter 의 `metadata.version` 과 같은 값을 쓴다.
올리는 기준은 저장소 README 의 "버전과 변경 이력" 을 따른다.

## 1.7.0

- **INDEX 동기화 검사가 INDEX.md 의 형식을 강제하지 않는다.**
  표(`| ADR-NNN |`) 행만 읽고 있어 목록형(`- [ADR-NNN](...)`) 저장소에서는 0 개를 뽑고,
  본문 번호 전체를 누락으로 보고했다. 실측한 저장소 다섯 곳 중 넷이 목록형이었다.
  번호만 긁어 비교하도록 바꿔 표형과 목록형을 모두 잡는다.

## 1.6.0

- 검사 스크립트 위치를 `.claude`로 고정하지 않고 실제로 로드한 스킬 디렉터리를 사용하게 했다.
- 범위가 없을 때 전체 저장소를 자동 선택하지 않고 현재 경로와 변경 파일에서 가장 좁은 범위를 추론한다.
- 정적 검사에 문서 범위를 전달할 수 있게 하고 실제 검사한 Markdown 수를 표준 오류로 알린다.
- 정적 위반을 출력하고도 0으로 끝나던 계약을 바로잡아 위반이 있으면 종료 코드 1을 반환한다.
- 검토 역할의 읽기 전용 경계에 commit과 push 금지를 명시하고 런타임 전용 회신 도구 지시를 제거했다.
- 반복 설명과 고정 형식 예시를 줄이고 여섯 감사 축, 승인 경계와 재검증 계약만 남겼다.

## 1.5.0

- **이스케이프한 물결표를 취소선 위험으로 보고했다.** `common-pitfalls` 가 제시하는 대응책이
  `\~` 이스케이프인데 검사기가 그것을 인정하지 않아, 지침을 따른 문서가 계속 위반으로 잡혔다.
  세기 전에 `\~` 를 제거한다.
- **ADR 부분 대체 표기를 정식 필드로 만들었다.** 기존 규정은 "대안 기각에 한 줄 추가" 였는데,
  대안 기각은 "처음에 왜 그 옵션을 안 골랐나" 를 담는 자리라 나중에 뒤집힌 사실을 넣으면
  시간 순서가 뒤섞이고 눈에도 띄지 않는다. `대체된 부분` 을 결정 바로 아래 두게 했다.
  작성 쪽 규칙은 planning 7단계가 함께 갖는다. 감사 쪽에만 있으면 사후 교정만 되고 예방이 안 된다.

## 1.4.0

- **`static-check.sh` 의 링크 검사가 로컬 파일이 아닌 것까지 검사했다.** OCR.API 감사에서
  깨진 링크 13건이 나왔는데 9건이 오탐이었다. 진짜 결함이 노이즈에 묻힌다.
  - `http`·`mailto` 만 예외 처리해 `dooray://` 같은 앱 스킴을 상대 경로로 취급했다. 예외를 `*://*` 로 넓혔다.
  - `/` 로 시작하는 경로는 발행 사이트의 루트 기준 URL 관례인데 상대 경로로 붙여 항상 없는 파일이 됐다. 함께 제외했다.
- **안내 문장을 실제 ADR 로 셌다.** Index 동기화 검사가 본문 아무 곳의 `ADR-NNN` 을 다 세어,
  "향후 ADR은 ADR-009부터 추가" 같은 문장이 실재하지 않는 ADR 로 잡혔다. 헤딩만 세게 고쳤다.
- **`INDEX.md` 가 없는 구조에서 항상 불일치를 보고했다.** 없는 파일을 빈 Index 로 취급해
  본문 번호 전체가 누락으로 잡혔다. 파일이 있을 때만 검사한다.
- **ADR 30줄 초과 과대화 검사를 제거했다.** 줄 수는 그 ADR 이 구현 세부로 변질됐는지와
  상관이 약하다. 단일 파일 ADR 레포에서는 일반 문서까지 잡아 리포트가 오탐으로 덮였다.
  B 축은 의미 검사가 판정한다.

## 1.3.0

- **"승인 없이 수정하지 않는다" 가 4곳에 있었다.** 도입부 중복을 걷고,
  이유가 붙은 실행 지점(5단계)과 description 만 남겼다.
- "오버레이는 코어를 덮어쓰는 게 아니라 채운다" 를 지웠다.
  바로 위에서 "먼저 읽고 코어보다 우선한다" 로 동작을 이미 규정했다.
- "핵심 철학" 절을 없애고 판단에 쓰이는 두 줄만 "검증 6축" 머리에 붙였다.
  판정 기준은 `references/six-axis.md` 가 소유한다.

## 1.2.0

같은 날 1.1.0 으로 먼저 커밋했다가 공백 파일명 수정이 더해져 1.2.0 으로 올렸다.

- `static-check.sh` 가 `git ls-files` 로만 입력을 잡아 미추적 신규 문서를 건너뛰었다.
  추적·미추적을 함께 보게 고쳐 "출력 0 줄" 이 거짓 통과가 되지 않게 했다.
- `for f in $(md_files)` 가 공백 있는 파일명을 쪼개 검사를 조용히 건너뛰던 것을 고쳤다.
  실측: fos-brain 의 `full-text search.md` 등에서 위반 4건이 누락되고 있었다.
- 위임 불가 시 조용히 자기 검증으로 대체하지 않고 리포트에 명시하게 했다.
- 앞 절이 이미 소유한 "의도적으로 안 하는 것" 절과 중복 설명을 걷어냈다.

## 1.0.0
