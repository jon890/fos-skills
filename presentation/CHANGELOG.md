# CHANGELOG: presentation

버전은 `SKILL.md` frontmatter 의 `metadata.version` 과 같은 값을 쓴다.
올리는 기준과 쓰는 형식은 저장소 README 의 "버전과 변경 이력" 을 따른다.

## 1.3.0 (2026-10-29)

- 개인 로컬에서 fos-skills 플러그인으로 올렸다. 설치하면 `presentation` 스킬이 뜬다
- `check-deck.py` 가 금지어를 `korean-check` 스킬의 「어색한 말 매핑 표」 에서 읽는다. 전에 읽던 개인 규칙 파일의 표 제목이 바뀌어 금지어 검사가 종료 코드 2 로 멈추던 문제도 이때 고쳤다
- `--browser` 가 이 저장소의 `tools/browser-driver` 를 먼저 찾는다
- 언어 규칙 참조를 `korean-check` 스킬의 `references/` 로 바꿨다

## 1.2.0 (2026-09-04)

- 스킬 안의 절대경로 다섯을 번들 상대경로로 바꿨다
- 행동 지시의 부정형 둘을 긍정형으로 바꿨다

## 1.1.0 (2026-09-04)

- 금지어를 사본으로 들지 않고 전역 매핑 표를 읽는다. `<style>` 과 `<script>` 는 금지어 검사에서 뺀다
- 브라우저 검사가 실패하면 위반으로 낸다. 노트 누락도 위반으로 올렸다
- 장을 세는 정규식이 속성 순서에 상관없이 동작한다
- 템플릿의 `<title>`, `<link>`, 본 `<style>` 을 `<head>` 로 옮겼다

## 1.0.0 (2026-08-31)

- 첫 버전. 랩 세미나 발표 자료 한 건을 만들면서 겪은 것을 규칙으로 옮겼다
- 인터뷰 여섯 항목, 파일 규칙, 만드는 순서, 시간 재는 법
- 장을 판정하는 규칙 아홉 갈래와 조작키·컴포넌트 문서
- 예시 장 8개가 든 골격 템플릿 한 파일
- 장 수, 활성 장, JS 문법, 하드코딩 잔재, 금지어, 세로 넘침을 보는 `check-deck.py`
