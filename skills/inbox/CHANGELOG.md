# CHANGELOG: inbox

버전은 `SKILL.md` frontmatter 의 `metadata.version` 과 같은 값을 쓴다.
올리는 기준과 쓰는 형식은 저장소 README 의 "버전과 변경 이력" 을 따른다.

## 1.2.1 (2026-11-05)

- 예시 설정과 문서의 사내 테넌트, 프로젝트, 대화방 값을 자리표시자로 바꿨다

## 1.2.0 (2026-11-02)

- 보드의 알림 상자에서 `x` 다음 번호로 알림을 직접 넘기고 `z` 로 되돌린다. 저장은 `dismiss` 명령과 같은 넘김 기록을 쓴다

## 1.1.0 (2026-11-02)

- 저장소 필터에 `"enabled": false` 를 두면 그 저장소의 보드가 알림을 보지 않는다. `board` 가 받기를 띄우지 않고 `{"enabled":false}` 를 내서 보드의 알림 상자, 상태 줄의 「알림 n」, `i` 단축키가 없어진다
- 끈 저장소의 필터는 다른 보드의 미분류 판정에 세지 않는다

## 1.0.1 (2026-11-02)

- 메신저 메시지의 text 가 `{"type":0,"text":…}` JSON 문자열로 오면 그 안의 글을 발췌와 본문에 쓴다. 원문 JSON 이 보이지 않는다

## 1.0.0 (2026-11-02)

- 두레이 업무 댓글 멘션, 담당·참조로 온 새 업무, 메신저 멘션을 공통 알림 모델로 모은다
- `inbox.ts` 의 board, fetch, list, context, reply, dismiss 명령. reply 는 `--yes` 없이 등록하지 않는다
- 답변 앞에 보낸 사람의 멘션을, 끝에 설정 `signature`(기본 AI 작성 표기)를 붙인다
- 저장소의 `.orch/config/notification.json` 필터로 보드마다 그 프로젝트의 알림만 보인다. 미분류는 `defaultBoard` 에 모은다
