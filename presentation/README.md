# presentation

발표 자료를 HTML 슬라이드 덱 한 파일로 만들고 검수한다.

## 산출물

- `<YYYYMMDD>_<이름>_<주제>.html` 한 파일. 장, 발표자 노트, 캡처가 모두 그 안에 들어간다
- 캡처는 `data:image/png;base64,` 로 파일 안에 넣어 다른 기기에서도 열린다
- `check-deck.py` 의 구조 검사 결과. 종료 코드 0 통과, 1 위반, 2 검사기가 돌지 못함
- 리허설로 실제 분당 글자 수를 재서 계산한 소요 시간

발표 자료는 기본적으로 저장소에 커밋하지 않는다. 커밋하려면 사용자에게 먼저 확인한다.

## 사용 시점

「발표 자료」, 「발표 준비」, 「슬라이드」, 「슬라이드 덱」, 「세미나 자료」, 「발표 스크립트」,
「발표 장 검수」, 「deck」, 「presentation」 을 언급하면 쓴다.
이미 만든 덱을 고치거나 제목을 검수하는 요청도 여기 해당한다.

| 하려는 일 | 쓰는 스킬 |
| --- | --- |
| 발표 덱을 만들고 장을 검수한다 | `presentation` |
| 외부에 게시하는 본문을 등록 전에 보여준다 | `content-preview` |
| 저장소 문서가 코드와 맞는지 감사한다 | `docs-check` |

## 전제

- 덱을 짜기 전에 인터뷰로 발표 성격, 청중이 놀랄 한 지점, 도구를 드러내는 방식,
  시간과 질문 시점, 데모 여부, 부 구성을 정한다. 정하지 않고 시작하면 장을 만든 뒤 전부 다시 쓴다
- `python3` 로 `check-deck.py` 를 돌린다
- `~/.claude/rules/korean-style.md` 가 금지어의 단일 소스다. `KOREAN_STYLE_RULES` 로 경로를 바꿀 수 있다
- `node` 가 있으면 JS 문법을 검사하고, 없으면 그 항목을 건너뛴다
- `~/.claude/scripts/browser-driver` 가 있어야 `--browser` 로 세로 넘침을 잰다. 없으면 건너뛴다
- 덱은 저장소 밖에서 만들므로 `assets/` 와 `scripts/` 를 절대 경로로 가리킨다
- Google Fonts 를 받으므로 망이 없는 발표장에서는 화면이 달라진다. 발표 전에 망 없이 한 번 열어 확인한다

## 구성

| 파일 | 소유하는 것 |
| --- | --- |
| `SKILL.md` | 인터뷰 항목, 파일 이름 규칙, 만드는 순서, 고칠 때의 규칙, 시간 재는 방법 |
| `references/slide-rules.md` | 장을 판정하는 규칙 목록. 내용과 형태로 나뉘며 각 규칙에 판정 문장이 붙는다 |
| `references/deck-mechanics.md` | 조작키, 컴포넌트 클래스, 애니메이션, 노트 편집이 `localStorage` 에 묶이는 문제 |
| `assets/deck-template.html` | 덱 골격 전부. 색 변수, 글꼴, 컴포넌트, 조작 스크립트가 들어 있다 |
| `scripts/check-deck.py` | 장 수와 주석 번호, 활성 장 개수, JS 문법, 남은 하드코딩 값, 노트 누락, 금지어, 세로 넘침을 검사한다 |
| `CHANGELOG.md` | 버전 이력 |
