# CHANGELOG: verify

## 1.5.0 (2026-11-04)

- PR 전 실행 검증과 PR 뒤 자동 코드 리뷰를 나누고 리뷰 대기를 최종 통과로 쓰지 않아요.

## 1.4.0 (2026-11-03)

- 도메인 규칙 변경이 있으면 문서·코드·평가 사례의 일치 여부를 규칙 ID 별로 확인해요.

## 1.3.0 (2026-11-03)

- 검증 계획의 누락을 독립적으로 대조하고 결과 양식에 실행 증거를 남겨요.

## 1.2.0 (2026-11-03)

- 기술 설계를 함께 검증하고 구조 결함은 technical-design 으로 돌려보내요.

## 1.1.0 (2026-11-02)

- 오버레이가 코드 리뷰를 PR 자동 리뷰에 맡긴다고 정하면 코드 검토자를 띄우지 않고 문서 정합성과 인수 검증만 한다
- 결정 누락은 spec, 계획 결함은 planning, 구현 결함은 build 로 나눠 돌려보낸다

## 1.0.0 (2026-11-01)

- 독립 리뷰와 스펙 기준 실행 검증을 구현 단계에서 분리한다
