- 머지 관문(`orch queue gate`, 머지 큐, 상주 루프의 자동 머지)이 PR 본문의 기능 완료 근거 블록으로 판정하지 않는다. 필수 체크, 설정한 리뷰 조건, 미해결 리뷰 스레드, 충돌, 통합 테스트 기록, 비공개 낱말처럼 이미 있는 사실만 본다.
- 머지 뒤 마무리, 정리, 보드 동기화도 본문의 `후속 검증` 줄로 막거나 배포 뒤 할 일을 만들지 않는다. 머지 사건 단계는 PR 이 MERGED 면 끝난다. 배포 뒤 확인은 보드 단계로 남긴다.
- 기능 완료 근거 양식(`templates/feature-evidence.md`)을 지운다. verify 결과는 PR 본문에 자유 형식으로 적는다.
