# CHANGELOG: content-preview

버전은 `SKILL.md` frontmatter 의 `metadata.version` 과 같은 값을 쓴다.
올리는 기준은 저장소 README 의 "버전과 변경 이력" 을 따른다.

## 2.0.0

**목표: 외부로 나갈 본문을 등록 전에 실제 렌더링으로 보여주고, 사용자가 읽은 뒤에 등록한다.**

- 본문 전문을 채팅에 다시 쓰지 않는다.
- 미리보기 턴은 미리보기로 끝낸다.

실행은 5단계다. 단계마다 통과 조건이 정해져 있다.

| 단계 | 통과 조건 |
| --- | --- |
| 수신자와 문체 | 누가 읽는지 정했고, 개인 문체 참조가 있으면 본문을 쓰기 전에 읽었다 |
| 본문 작성 | 본문 파일의 첫 줄이 새 내용이다 |
| 자가 점검 | 점검 목록을 통과했다 |
| 미리보기 | 사용자가 보는 워크트리의 탭에 새 본문이 떠 있다 |
| 등록 | 사용자가 읽고 응답한 다음 턴이다 |

개인 문체 참조를 어디에 두고 무엇을 적는지는 `references/persona.md` 로 옮겼다.

브라우저 드라이버를 저장소가 함께 배포한다.
`show-preview.sh` 가 호출자 지정, 저장소 안, 개인 심링크 순으로 찾는다.
저장소마다 스킬 배치가 한 단 달라 고정 상대경로로는 둘 다 맞출 수 없어, 위로 올라가며 찾는다.

PUBLIC 저장소에 들어 있던 사내 프로젝트와 저장소 이름을 뺐다.
`--project` 의 기본값이 사내 프로젝트명이라 인자를 주지 않으면 미리보기 머리에 그대로 렌더됐다.
기본값을 비우고, 값이 없으면 그 줄을 그리지 않는다.
