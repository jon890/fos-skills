# harness-cleanup

하네스 지침이 현재 설정과 실행 결과에 맞는지 감사하고, 사용자 승인을 받아 고친다.

## 산출물

수정보다 판정표가 먼저 나온다. 사용자가 승인한 항목만 고친다.

| 산출물 | 내용 |
| --- | --- |
| 판정표 | 대상 절, 유지·제거·축소·추가·보류 판정, 근거, 실측·도구 대체·가이드·추정 등급을 한 줄씩 |
| 수정 diff 와 커밋 | 승인받은 항목만 반영한다. 오류로 판정하지 않은 유지와 보류 항목은 그대로 둔다 |
| 재검증 결과 | 처음 실행한 측정을 같은 범위에서 다시 실행한 값. 바꾼 동작에는 양성과 음성 대조 표본 |
| 완료 보고 | 처리한 판정, 전후 측정, 실행한 검증, 커밋, 남은 검증 공백 |

감사 대상은 `scripts/collect_targets.py` 가 내는 목록이다. 어떤 파일이 대상인지는 `scripts/target_files.py` 가 소유한다.
스킬 하나만 감사할 때는 `--scope <저장소 안 경로>` 로 대상 범위를 정한다.
저장소 밖을 가리키는 심볼릭 링크는 표시만 하고 수정하지 않는다.

## 사용 시점

지침과 스킬 본문이 실행 환경과 어긋났는지 확인할 때 쓴다.
"하네스 정리", "지침 감사", "스킬 지침 점검", "프롬프트 교정" 같은 요청이 여기 해당한다.

| 하려는 일 | 쓰는 스킬 |
| --- | --- |
| 지침과 스킬 본문이 현재 환경과 맞는지 감사한다 | `harness-cleanup` |
| 일반 제품 문서와 planning 산출물이 코드와 맞는지 감사한다 | `docs-check` |
| 스킬을 새로 만들거나 파일 구조를 바꾼다 | `skill-creator` |

## 전제

- **감사할 저장소 경로.** 검사 스크립트가 감사 대상 저장소 루트를 첫 인자로 받는다. `run_doc_snippets.py` 는 문서 파일을 받는다.
- **`python3`, `bash`, `zsh`.** 검사는 모두 python 이고,
  `run_doc_snippets.py` 가 문서의 코드 블록을 bash 와 zsh 양쪽에서 돌려 셸 차이를 본다.
- **현재 실행 환경의 설정과 도구 설명.** 실제 모델과 런타임, 설치된 역할과 스킬,
  프로젝트가 읽는 지침 파일을 여기서 확인한다. 찾지 못하면 검증 공백으로 둔다.
- **사용자 승인.** 판정표를 제시한 뒤 승인받은 항목만 수정한다.
- **저장소의 표현·가독성 검사.** 고친 Markdown 이 이것을 통과해야 한다.

## 구성

| 파일 | 소유하는 것 |
| --- | --- |
| `SKILL.md` | 목표와 단계별 절차, 단계별 통과 조건, 실측 명령, 판정표 형식, 조사를 나눠 맡기는 방식 |
| `references/audit-axes.md` | 무엇을 찾을지. 감사 축마다 찾는 방법과 실측 사례 |
| `references/judgment.md` | 찾은 것을 유지할지 지울지. 유지와 제거의 기준, 문장 단위 판정 축, 도구가 강제하는지 확인하는 절차 |
| `references/run-doc-snippets.md` | 감사 대상 문서의 bash 블록을 돌리는 절차와 안전 조건 |
| `references/script-audit.md` | 범위에 Markdown 없이 스크립트만 있을 때의 감사 절차 |
| `scripts/target_files.py` | 감사 대상 파일 선택 기준과 `--scope` 해석. 다른 스크립트가 이것을 가져다 쓴다 |
| `scripts/collect_targets.py` | 감사 대상 파일과 줄 수 출력 |
| `scripts/find_test_requirements.py` | 지우거나 이름을 바꿀 문자열을 테스트와 CI 설정이 요구하는지 찾는다 |
| `scripts/check_references.py` | 지침이 가리키는 파일, 절, 스킬이 실재하는지 확인 |
| `scripts/check_facts.py` | 문서에 적힌 개수와 목록 표기를 검토 지점으로 제시. 자동 판정이 아니다 |
| `scripts/check_duplication.py` | 지침 파일 사이에 같은 내용이 반복되는 구간 검출 |
| `scripts/check_rename_drift.py` | `SKILL.md` 를 고치고 그것이 위임한 참조 문서를 안 고친 경우 검출 |
| `scripts/check_enforcement.py` | 지침이 금지하는 대상을 다른 수단이 실제로 막는지 판정 |
| `scripts/run_doc_snippets.py` | 문서의 bash 코드 블록을 그대로 추출해 bash 와 zsh 에서 실행 |
| `CHANGELOG.md` | 버전 이력 |

실행 절차는 `SKILL.md` 가, 각 스크립트의 사용법과 종료 코드는 그 파일 머리의 docstring 이 소유한다.
