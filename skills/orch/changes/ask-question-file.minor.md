- `orch worker ask` 에 `--question-file <파일>` 을 더했다. 긴 결정 블록을 셸 인자로 붙이지 않고 파일로 보낼 수 있고, `--decision` 이면 파일 내용의 첫 줄을 검사한다.
- 결정 블록이 한 질문에 4개를 넘으면 보내지 않고 「4개씩 나눠 질문마다 보낸다」 고 알린다. 사용자에게 묻는 도구가 한 번에 4개까지라 다섯째 결정부터 답이 빠지던 일을 막는다.
- 답을 받으면 결정 블록 수와 `D1=` 답 줄 수를 맞춰 본다. 바로 받은 답은 빠진 번호를 stderr 로 알리고, 깨운 뒤 읽은 답은 `--check-answer` 로 대조한다.
