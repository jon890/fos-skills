# inbox

업무 도구에서 나를 태그한 알림을 찾아다니지 않게 한다.
두레이 업무 댓글의 멘션, 담당이나 참조로 온 새 업무, 메신저 멘션을 5분마다 모아 `/board` 창에 보이고, 맥락을 읽은 답변 초안을 내가 확인한 뒤 등록한다.
작성자 id 를 이름으로 풀어 받는 사람을 틀리게 적는 일이 없고, 확인 없이는 등록하지 않는다.

도구는 adapter 로 붙는다. 첫 adapter 는 두레이이고, Slack 같은 도구는 adapter 파일 하나를 더해 붙인다.
프로젝트마다 오케스트레이터를 두면 저장소 필터로 그 보드에 그 프로젝트의 알림만 보인다.
알림이 필요 없는 저장소는 필터에 `"enabled": false` 를 두어 보드의 알림 상자와 `i` 단축키를 없앤다.

## 이럴 때 쓴다

- 업무 댓글에서 태그됐는데 놓칠까 걱정된다
- 여러 프로젝트의 보드를 따로 띄우고, 보드마다 그 프로젝트 알림만 보고 싶다
- 태그된 댓글에 앞 대화를 읽고 답하고 싶다

"알림 확인해 줘", "태그된 거 답해 줘", "멘션 온 거 봐 줘" 처럼 말하거나 `/board` 에서 숫자 키나 `i` 를 누르면 이 스킬이 뜬다.

## 사용 예시

업무 번호, 이름, 시각은 예시다.

```text
/board:  알림  2  ·  14:03 확인
         1: ● 어드민개발/81 어드민 권한 정리 [두레이]  김철수 · 멘션 · 12분 전
              「운영 계정도 같은 권한이 필요한지 확인 부탁드려요」
         2: ● EXAMPLE-PROJECT/342 배포 일정 조율 [두레이]  이영희 · 담당 · 1시간 전

나:      (1 을 누르고 Enter)

스킬:    어드민개발/81 의 앞 댓글 4개를 읽었습니다. 김철수 님이 운영 계정에도 같은 권한이 필요한지 묻습니다.
         등록될 본문입니다. 받는 사람: 김철수, 등록할 곳: 어드민개발/81 댓글
           @김철수 운영 계정은 조회 권한만 필요합니다. …
           🤖 이 메시지는 AI가 작성했고, 작성자가 검토했습니다.
         등록할까요?

나:      응

스킬:    등록했습니다: https://example.dooray.com/project/tasks/…
```

## 받는 것

- `/board` 의 알림 상자: 새 알림 수, 항목 줄, 받지 못한 출처의 오류, 다른 보드에 속하지 않은 미분류 알림 수
- 보낸 사람을 멘션하고 AI 작성 표기를 붙인, 내가 확인한 답변 댓글이나 메시지
- 답한 알림의 「답함」 표시와, 답할 필요 없는 알림의 넘김 기록

## 준비

- `node` 24 이상과 `dooray` CLI 로그인이 필요하다. 업무 피드를 읽는 `dooray stream list` 명령이 있는 CLI 버전이어야 한다
- `~/.config/fos-skills/inbox.json` 에 켤 adapter 를 적는다. 이 파일이 없으면 알림함이 꺼진다. 형식은 [config.md](references/config.md) 에 있다
- 프로젝트별로 나누려면 각 저장소의 `.orch/config.json` 의 `inbox` 절에 볼 두레이 프로젝트와 대화방을 적는다(옛 `.orch/config/notification.json` 은 이번 major 동안 함께 읽는다)

## 함께 쓰는 스킬

- `/board` 창은 `work-board` 가 그린다. 이 스킬은 보드가 부르는 명령과 답변 절차를 맡는다
- 등록 전 렌더링은 `content-preview`, 한국어 점검은 `korean-check` 가 맡는다
- 두레이 업무 문서 작성과 진행 기록 댓글은 `dooray-task` 가 맡는다
