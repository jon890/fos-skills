# 덱 골격과 편집 함정

`assets/deck-template.html` 한 파일이 골격 전부다. 빌드 없이 브라우저로 바로 연다.
글꼴만 Google Fonts 에서 받는다. 대체 글꼴이 있어 깨지지는 않지만 망이 없는 발표장에서는
화면이 달라진다. 발표 전에 망 없는 상태로 한 번 열어 확인한다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← → | 장 넘김. 좌우 클릭 영역도 같다 |
| `N` | 발표자 노트. 그 안에서 직접 고칠 수 있다 |
| `S` | 전체 스크립트. 편집 모드가 있다 |
| `O` | 장 개요 판. 클릭하면 그 장으로 간다 |
| `F` | 전체 화면 |
| 캡처 클릭 | 확대 모달 |

노트 편집은 브라우저 `localStorage` 에 장 제목을 키로 저장한다.
**제목을 고치면 그 장의 편집이 분리된다.** 발표 직전에 제목을 고치지 않는다.

## 컴포넌트

| 클래스 | 무엇 |
| --- | --- |
| `.faceoff` | 좌우 대비. 제목 하나에 문단 몇 줄 |
| `.pairs` / `.pair` | 왼쪽 이름과 오른쪽 설명을 화살표로 이은 목록 |
| `.chain` / `.node` | 순서 흐름. `.node.tool` 은 도구, `.node.human` 은 사람이 판단하는 칸 |
| `.loops` / `.loopbox` | 흐름 여러 개를 위아래로. `.backedge` 가 되돌아가는 조건 |
| `.figs` / `.fig` | 큰 숫자 카드. `.fig.hot` 은 강조 |
| `.talk` / `.turn` | 정적 대화. `.turn.me` 와 `.turn.ai` |
| `.cc` | Claude Code 재현 애니메이션 |
| `.term` | 터미널 출력. `<span>` 색은 `.o .g .r .h .c .p` |
| `.memos` / `.memo` | 붙임쪽지. `.memo.api` 는 검은 응답 블록 |
| `.toc` / `.toc-row` | 목차 |
| `.t-wrap` + `<table>` | 표. `.num` 은 숫자 정렬, `tr.hi` 는 강조 행 |
| `.slide.part` | 부 전환. `.pno` 와 `.pdesc` |
| `.lede` | 장을 맺는 한 문장 |

## Claude Code 재현 애니메이션

대사는 JS 의 `CC_STEPS` 배열이 소유한다.

| 종류 | 필드 | 화면 |
| --- | --- | --- |
| `you` | `text` | `>` 줄. 한 글자씩 타이핑 |
| `tool` | `name`, `arg`, `res` | `⏺ name(arg)` 뒤에 `⎿ res` |
| `ai` | `text` | `⏺` 줄. 조금 빠르게 타이핑 |

- 그 장으로 넘어오면 자동 재생하고, 벗어나면 최종 상태로 둔다.
- `prefers-reduced-motion` 이면 애니메이션 없이 최종 화면을 바로 보여 준다.
- `.cc-body` 에 `min-height` 를 준다. 없으면 재생 중 아래 내용이 밀려 내려간다.
- **도구 줄에 쓰는 값은 저장소에 실제로 있는 것만 쓴다.** 그날 대화 원문은 대개 남아 있지 않으므로,
  파일명과 값은 지금 확인할 수 있는 것으로 채우고 바에 `재현` 이라고 표시한다.

## 파일을 고칠 때 지키는 것

한 파일이 1,300줄을 넘어 편집 사고가 파일 전체를 날린다. 실제로 한 번 날렸다.

- **여러 줄 블록을 정규식으로 지우지 않는다.** 같은 주석이 CSS 와 JS 양쪽에 있어 엉뚱한 쪽이 지워진다.
  줄 번호로 경계를 확인하고 그 범위만 자른다.
- 큰 편집 전에 사본을 뜬다.
- 편집 뒤 `scripts/check-deck.py <파일>` 을 돌린다.
- 문자열 교체는 `count == 1` 을 확인한 뒤 바꾼다. 여러 곳이 걸리면 의도가 아니다.

파일을 잃었을 때 브라우저 탭이 아직 열려 있으면 `document.documentElement.outerHTML` 로 되찾을 수 있다.
한 번에 다 못 받으므로 20만 자씩 나눠 받아 이어 붙인다.

## 검사

```bash
python3 scripts/check-deck.py <deck.html>            # 구조·JS·금지어
python3 scripts/check-deck.py <deck.html> --browser  # 세로 넘침까지
```

`--browser` 는 `~/.claude/scripts/browser-driver` 를 쓴다. 없으면 그 항목만 건너뛴다.

검사기가 보는 것과 사람이 봐야 하는 것이 갈린다.

| 검사기 | 사람 |
| --- | --- |
| 장 수와 주석 번호, active 장 1개 | 장마다 주장이 하나인가 |
| JS 문법, `<script>` 쌍 | 숫자에 근거가 있는가 |
| 이전 버전에서 남은 하드코딩 값 | 주어와 목적어가 있는가 |
| 금지어 | 목차와 부 전환이 실제 장과 맞는가 |
| 세로 넘침 | 제목이 무엇이 일어났는지 말하는가 |

## 겪은 함정

| 증상 | 원인 | 대응 |
| --- | --- | --- |
| 발표자 노트가 비어 보인다 | `template.textContent` 는 빈 문자열이다 | `t.content.textContent` 를 읽는다 |
| 개요 버튼이 두 배로 늘어난다 | JS 가 `appendChild` 만 하는데 HTML 에 옛 목록이 박혀 있다 | 컨테이너를 빈 채로 두고 JS 가 채우게 한다 |
| 장 하나가 다음 장을 삼킨다 | `</section>` 이 빠졌다 | `check-deck.py` 의 장 수로 잡는다 |
| 두 칸 배치가 깨진다 | `.split{display:grid}` 위에 `.asks{display:flex}` 를 같은 요소에 얹었다 | 바깥에 `.split.two`, 안쪽에 다른 클래스를 둔다 |
| 전체 화면 버튼을 누른 뒤 스페이스바가 안 먹는다 | 버튼에 포커스가 남았다 | 누른 뒤 `blur()` 한다 |
