# orch: 같은 등급의 두 모델을 번갈아 띄운다

확인: 2026-11-23

## 목표

모델 표의 각 행은 등급만 정한다. `orch worker launch` 는 그 등급의 두 모델(Claude 와 Codex)을 번갈아 골라 띄운다.
행마다 한 제공자를 기본값으로 정해 두지 않는다.

2026-11-23 ai-analysis 에서 11시 뒤 띄운 worker 26개가 모두 Codex `gpt-6.2-sol` 이었다. 모델 표의 구현·작은 수정·설계 행 기본값이 sol 이었기 때문이다(11/17 결정, 비용이 Opus 의 약 40%).
같은 등급 대응(Fable ↔ astra, Opus ↔ sol, Sonnet ↔ terra·sol, Haiku ↔ luna, 사용자 결정 2026-11-20)은 사용 한도에 걸렸을 때만 쓰였다.
사용자 결정(2026-11-23): 같은 등급의 두 모델은 서로 대신할 수 있으므로 기본값을 두지 않고 번갈아 쓴다.

## 범위

이번 범위:

- 모델 표의 행을 「등급」 으로 바꾸고, 등급마다 두 모델(과 effort)을 둔다. 같은 등급 대응은 지금 「사용 한도에 걸렸을 때」 표를 쓴다.
- 띄울 때 등급마다 이 장비 전체에서 센 차례로 두 모델을 번갈아 고른다.
- 고른 모델이 바닥났으면 지금처럼 같은 등급의 다른 모델로 띄우고, 둘 다 바닥났으면 띄우지 않는다([exhausted-model-avoid](../exhausted-model-avoid/spec.md)).
- 어려운 설계·구현 행도 Fable 과 `gpt-6.2-astra` 를 번갈아 쓴다. 11/20, 11/23 의 astra 제한(가장 어렵고 복잡한 일에만, Fable 한도 대응)을 푼다.

범위 밖:

- 리뷰 worker 의 제공자. 지금처럼 만든 쪽과 다른 제공자가 맡는다.
- 새 모델이 나왔을 때의 짝 비교 절차(`model-compare`). 그대로 둔다.
- 계정 선택. 지금처럼 사용자가 정한다.
- 저장소 CI 의 리뷰 모델(예: ai-analysis 의 Claude 리뷰 워크플로).

## 요구사항과 인수 조건

| ID | 요구사항 | 관측할 인수 조건 |
| --- | --- | --- |
| REQ1 | 등급의 두 모델을 번갈아 띄운다 | 같은 등급의 행으로 띄울 때마다 Claude 와 Codex 모델이 번갈아 뜬다. 연속으로 띄운 두 worker 가 같은 등급이고 둘 다 바닥나지 않았으면 서로 다른 제공자다 |
| REQ2 | 차례는 이 장비 전체에서 등급별로 센다 | 서로 다른 저장소에서 같은 등급으로 띄워도 하나의 차례를 이어서 쓴다. 등급이 다르면 차례가 따로다. 두 띄우기가 동시에 와도 같은 차례를 두 번 쓰지 않는다 |
| REQ3 | 바닥난 모델은 건너뛴다 | 차례인 모델이 바닥났으면 같은 등급의 다른 모델로 띄우고 차례를 넘긴다. 둘 다 바닥났으면 exhausted-model-avoid 의 REQ5 대로 띄우지 않는다 |
| REQ4 | 지시서는 등급만 적는다 | 지시서의 `worker 선택:` 이 행(등급)과 그 등급의 어느 한 모델을 적어도 거절하지 않고 차례대로 띄운다. 띄운 모델과 이유(`번갈아: <등급> 차례`)가 `LAUNCH-EFFECTIVE` 와 띄우기 기록에 남는다 |
| REQ5 | 직접 고른 모델은 그대로다 | 지시서에 `후보 밖:` 으로 고른 모델은 차례를 쓰지 않고 그 모델로 띄운다(바닥났으면 REQ3) |
| REQ6 | 리뷰는 만든 쪽과 다른 제공자다 | 리뷰 worker 는 차례를 쓰지 않고, 리뷰할 PR 을 만든 worker 와 다른 제공자의 같은 등급 모델로 뜬다 |
| REQ7 | 이어 가기는 모델을 바꾸지 않는다 | `orch worker resume` 과 `--terminal` 이어 쓰기는 앞 세션의 모델로 이어 간다. 새 띄우기, `--task` 재시도, `orch worker relaunch` 는 차례를 쓴다 |
| REQ8 | 모델 표와 문서가 등급을 말한다 | `agent-selection.md` 의 모델 표는 행마다 등급과 그 등급의 두 모델을 보인다. 「기본 후보에서 뺀 모델」 의 astra 제한 문구를 지운다 |
