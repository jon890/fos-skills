## 검토 범위

스펙·설계·검증 커밋·관련 PRD/flow/공유 계약/ADR 경로. 없는 문서를 생성 목록으로 만들지 않는다.

## 문서 정합성

| 문서 | 바뀐 사실 또는 영향 없음의 근거 | 처리·재검토 결과 |
| --- | --- | --- |
| 기능 design.md | 실제 변경을 대조해 작성 | 정합 / 문구 수정 / 앞 단계 반환 |
| 도메인 문서·출력 계약 | 바뀐 규칙이 문서와 실제 적용 자리에 빠짐없이 반영됐는지, 중복·상충이 없는지 대조 | 정합 / 규칙 변경 없음 / spec 또는 기능 PR 반환 |

## 공통화 후보

후보 없음: 비교한 관련 기능·계약과 반복 규칙이 없는 이유.
후보가 있으면 두 근거 위치, 공통점·차이, 제안할 소유 위치를 적는다. 이 PR 의 필수 계약 수정과 후속 공통화는 구분한다.
여러 스펙에 흩어진 같은 도메인 규칙은 근거 위치들과 옮길 도메인 문서를 적는다.
