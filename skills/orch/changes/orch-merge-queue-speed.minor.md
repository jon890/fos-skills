- 상주 루프의 최신화가 필수 체크만 보고 CI 상태를 정한다. 필수가 아닌 리뷰 봇만 실패한 PR 도 미리 최신화한다.
- 공통 지시서에 「기준 브랜치는 충돌이나 코디네이터·큐의 요청이 있을 때만 합친다」 규칙을 더했다.
- `queue.shared_groups`(공용 묶음)를 더했다. PR 과 base 가 같은 묶음을 둘 다 바꿨을 때만 다시 합친다.
- `pipeline.slow_sec` 을 주면 보드 동기화와 정리를 따로 돌아, 느린 단계가 머지, CI, 메시지 확인을 막지 않는다.
- `queue.auto_review.fallback` 을 두면 리뷰 봇이 몇 초 만에 실패한 PR 에 루프가 리뷰 worker 를 바로 띄운다.
