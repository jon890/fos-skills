- 창이 보드 항목 아래에 작업 중 worker 를 역할·워크트리·PR·CI·상태로 한 줄씩, 끝난 worker 를 「✓ 끝난 worker N」 한 줄로, 끊긴 worker 를 빨간 줄로 그린다. 펼친 보기(d)는 모든 줄을 그리고 완료 항목은 작업 중 줄만 그린다
- 작업 중 줄이 있으면 「worker 없음」 을 그리지 않는다. 작업 중 줄이 붙잡은 worker 는 「항목에 없는 워커」 에 넣지 않는다
- 보드 명령에 `worker-add --stages` 와 `worker-set` 을 더한다. 후속 줄의 단계 번호도 사건 단계로 본다
