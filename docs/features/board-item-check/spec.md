# 보드 항목 상태 확인 단축키

확인: 2026-11-03

## 목표

`/board` 창에서 진행 중이거나 대기 중인 항목을 골라, 그 항목의 지금 상태를 확인하고 다음 단계를 이어 가라는 요청문을 입력란에 바로 채운다.

## 범위

- 대상은 work-board 의 `/board` 창과 그 등록 훅(`work-board/hooks/register.js`)이다.
- 범위 밖: 완료(done) 항목과 펼친 보기의 상세 줄, 요청문을 자동으로 보내기(훅의 텍스트는 코디네이터 모델에 닿지 않아 사람이 Enter 로 보낸다).

## 요구사항과 인수 조건

| ID | 요구사항 | 관측할 인수 조건 |
| --- | --- | --- |
| REQ1 | `c` 를 누르면 진행 중(doing)과 대기(wait) 항목 앞에 화면 순서대로 `1`~`9` 번호가 뜬다 | 번호가 뜬 상태에서 알림 상자의 번호는 바뀌지 않는다. `Esc` 나 `c` 를 다시 누르면 번호가 사라진다 |
| REQ2 | 번호를 누르면 그 항목의 확인 요청문이 입력란에 채워진다 | 요청문에 항목 id, 제목, 끝나지 않은 단계, worker, PR 번호가 들어 있다 |
| REQ3 | 요청문은 상태 확인과 다음 단계를 시킨다 | 요청문이 「PR·CI·배포·worker 보고·업무 상태와 대조해 지금 상태를 확인하고, 멈춰 있으면 다음 단계를 진행하거나 내가 정할 것을 물어 줘」 를 담는다 |
| REQ4 | 단축키 상자에 `c` 버튼은 대상 항목이 있을 때만 보인다 | 진행 중·대기 항목이 없으면 `c` 가 없다 |
| REQ5 | `c` 를 누르지 않아도 진행 중·대기 항목의 제목 줄을 클릭하거나, 그 줄에 포커스를 두고 Enter 를 누르면 같은 확인 요청문이 채워진다 | 완료·결정 항목과 펼친 보기의 상세 줄은 눌리지 않는다. 숫자 단축키는 `c` 모드에서만 붙는다. 넘기기(`x`) 모드에서는 눌러도 채워지지 않는다 |

## 설계

- 번호 모드는 알림의 `x` 다음 번호(넘기기)와 같은 방식으로 둔다. 같은 코드 경로를 재사용한다.
- 요청문 문구의 원본은 `register.js` 의 상수 하나다(알림의 `replyPrompt` 와 같은 자리).
- 대상이 9개를 넘으면 화면 순서의 앞 9개만 번호를 받는다.
- 테스트: 번호 모드 진입과 해제, 번호별 요청문 내용, 대상 없음일 때 `c` 숨김, 알림 번호와 겹치지 않음.
- README 의 단축키 설명을 고친다.
