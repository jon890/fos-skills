# 보드 창: 항목 아래 요약 줄을 눌러 그 항목의 목록만 펼치고 접는다

확인: 2026-11-17

## 목표

보드 창의 접힌 보기에서 항목 아래 요약 줄(「✓ n개」, 「남은 단계 n개」, 「✓ 끝난 worker N」)을 누르면 그 항목의 해당 목록만 펼쳐지고, 다시 누르면 접힌다.
지금은 `d` 로 모든 항목을 한꺼번에 펼쳐야 해서, 항목 하나의 남은 단계나 끝난 worker 를 보려 해도 창 전체가 길어진다.

- 배경: ai-analysis 코디네이터가 사용자 요청을 넘겼다(2026-11-17). 「기존 보드 화면의 다른 접기 동작을 따른다」 는 조건이 붙었다.
- 지금 동작: 접힌 보기는 끝낸 단계를 「✓ n개」, 남은 단계를 「남은 단계 n개」, 끝난 worker 를 「✓ 끝난 worker N」 한 줄로 줄인다. `d` 는 모든 항목을 함께 펼치고 접는다(`extensions/work-board/references/behavior.md` 의 「접힌 보기」, 「펼친 보기」, 「worker 줄 그리기」).
  `d` 의 상태는 창 메모리의 값 하나이고 처음에는 접혀 있으며 파일에 남기지 않는다(`extensions/work-board/hooks/register.js` 의 `expanded`).

## 범위

이번 범위:

- 접힌 보기의 세 요약 줄을 항목별로 펼치고 접는 단추로 바꾼다

범위 밖:

- `d` 의 전체 펼치기 동작과 펼친 보기의 모양. 그대로 둔다
- 펼침 상태를 파일에 저장하는 것
- 완료 칸과 결정 항목의 요약 줄. 지금처럼 `d` 로만 펼친다

| REQ7 | 단계 목록에는 번호 있는 단계 줄만 보인다. 번호 없는 참고 줄은 `d` 로만 본다. 요약의 수는 지금처럼 막대와 같은 값을 쓰고 줄 수에 맞추지 않는다 | 참고 줄이 있는 항목에서 펼쳐도 참고 줄이 보이지 않는다 |
| REQ8 | 끝난 worker 를 펼치면 작업 중과 끊긴 worker 줄은 자리를 지키고, 요약 줄 자리에 끝난 worker 줄만 펼친 보기와 같은 모양으로 그린다 | 펼쳐도 작업 중 worker 줄의 위치가 바뀌지 않는다 |
| REQ2 | 펼친 목록의 단추를 다시 누르면 접힌다 | 다시 누르면 요약 한 줄로 돌아간다. 펼쳤을 때 단추 글에 접을 수 있음이 보인다 |
| REQ3 | 항목별 펼침 상태는 창 메모리에만 두고, 창을 새로 열면 모두 접혀 있다. 목록이 비어 단추가 사라지면 그 상태를 버린다 | 창을 닫았다 열면 모든 요약 줄이 접혀 있다. 남은 단계를 다 끝낸 뒤 새 단계가 생기면 접힌 채 나온다. 보드 파일이 바뀌지 않는다 |
| REQ4 | `d` 로 펼친 보기는 지금처럼 모든 줄을 보이고 항목별 단추를 그리지 않는다. 다시 `d` 로 접으면 항목별로 펼쳐 두었던 상태가 그대로 돌아온다 | `d` 를 두 번 누른 뒤에도 앞서 항목별로 펼친 목록이 펼쳐진 채다 |
| REQ5 | 넘기기(`x`) 모드에서는 요약 단추를 눌러도 아무것도 하지 않는다 | 넘기기 모드에서 눌러도 펼쳐지지 않는다(제목 줄 단추와 같은 규칙) |
