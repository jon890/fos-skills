# fos-skills 설치본을 루프가 자동으로 갱신하고, 세션은 쉴 때 스스로 다시 읽는다

확인: 2026-11-20

## 목표

main 에 fos-skills 의 새 버전이 올라가면, 상주 루프가 사람 손 없이 이 머신의 fos-skills 설치본을 모두 새 버전으로 갱신한다.
코디네이터 세션의 보드는 세션이 쉴 때 `/reload-plugins` 를 직접 실행해, 입력란을 건드리지 않고 새 버전을 읽는다.

지금은 사용자가 보드의 `p` 를 누르거나 코디네이터가 `claude plugin update` 를 직접 돌릴 때만 설치본이 바뀐다([보드 버전 표시 스펙](../board-plugin-version/spec.md) R3).
루프는 설치본이 바뀌면 스스로 다시 뜨지만([루프 자동 갱신 스펙](../loop-self-update/spec.md)), 설치본 자체는 갱신하지 않는다.
2026-11-20 하루에만 PR 7개를 머지하며 버전이 18.55.0 에서 18.61.0 까지 올랐고, 그때마다 보드에 「p 로 갱신」 이 떴다.
이 머신에는 `~/.claude` 와 Orca 계정 프로필 3개에 fos-skills 가 따로 설치돼 있다. 2026-11-13 에는 한 프로필의 옛 18.0.0 으로 루프가 돌았다(루프 자동 갱신 스펙 「조사한 사실」 의 실측).

## 범위

이번 범위:

- 루프가 30분마다 main 의 최신 버전을 확인하고, 뒤처진 설치본을 갱신한다.
- 이 머신의 모든 Claude 설정 폴더(`~/.claude` 와 Orca 가 아는 프로필)의 fos-skills 설치본을 대상으로 한다.
- 보드가 세션이 쉴 때 `/reload-plugins` 를 실행한다.
- orch 설정 한 줄로 끈다.

범위 밖:

- 입력란에 `/reload-plugins` 를 채우는 것. 사용자의 채팅을 방해하지 않는다.
- 작업 폴더(git 체크아웃)를 그대로 읽는 개발용 설치. 지금처럼 `p` 로만 받는다.
- fos-skills 밖의 다른 플러그인.
- 원격 머신.

## 요구사항과 인수 조건

| ID | 요구사항 | 관측할 인수 조건 |
| --- | --- | --- |
| REQ1 | 루프가 새 버전을 찾아 설치본을 갱신한다 | main 의 `.claude-plugin/plugin.json` version 이 설치본보다 높으면, 30분 안에 루프가 그 설치본을 `claude plugin update` 로 갱신한다. 갱신 명령이 성공해도 설치 기록의 version 이 main 과 같을 때만 성공으로 본다. 이미 최신이거나 설치본이 main 보다 높으면 갱신 명령을 부르지 않고 버전을 낮추지 않는다 |
| REQ2 | 모든 설정 폴더의 설치본을 갱신한다 | `~/.claude` 와 Orca 가 아는 프로필 가운데 fos-skills 설치 기록이 있는 폴더마다, 기록된 scope(user, project, local)별로 갱신한다. project·local 은 기록된 projectPath 에서 돈다. 설치 기록이 없는 폴더는 건너뛴다 |
| REQ3 | 개발용 설치는 건드리지 않는다 | 작업 폴더를 그대로 읽는 설치(directory 소스 마켓플레이스, `--plugin-dir`)는 갱신하지 않고, 그 폴더에서 git 명령을 돌리지 않는다 |
| REQ4 | 여러 루프가 동시에 갱신하지 않는다 | 저장소마다 루프가 떠 있어도 한 머신에서 갱신은 한 번에 하나만 돈다. 다른 루프가 갱신 중이면 그 틱은 건너뛴다. 성공한 버전으로는 다시 갱신하지 않고, 실패한 버전은 다음 확인(30분 뒤)에 다시 시도한다 |
| REQ5 | 갱신 결과를 알린다 | 설치본이 바뀌어 루프가 다시 뜰 때 보내는 「다시 떴다」 알림에 「fos-skills <새 버전> 설치됨, 세션은 쉴 때 다시 읽는다」 와 설치본마다의 결과(설정 폴더, scope, 옛 버전, 성공 또는 실패 이유)를 붙인다. 그래서 모든 루프의 코디네이터가 한 통으로 안다. 실패는 버전마다 한 번만 알리고, 보드는 지금처럼 「p 로 갱신」 을 보인다 |
| REQ6 | 세션이 쉴 때 스스로 다시 읽는다 | 설치본이 세션이 읽은 번들보다 새것이면(main 과 상관없이) 보드 머리 줄에 「새 버전 설치됨 · 쉴 때 다시 읽음」 이 보인다. 세션이 쉬면(돌고 있는 턴이 없으면) 보드가 입력란을 건드리지 않고 `/reload-plugins` 를 실행한다. 입력란에 쓰던 글은 그대로 남고, 채팅에는 그 명령의 결과 한 줄만 남는다. 다시 읽은 뒤에는 표시가 사라지고, 그래도 main 이 앞서 있으면 지금처럼 「p 로 갱신」 이 보인다 |
| REQ7 | 설정으로 끈다 | 루프가 도는 저장소의 orch 설정에 `plugin.auto_update` 가 `false` 면 그 루프는 확인도 갱신도 하지 않는다. 값이 없으면 켜진 것으로 본다 |

## 도메인 규칙 변경

도메인 규칙 변경 없음: 여러 기능이 참조하는 도메인 규칙을 바꾸지 않는다. 바뀌는 것은 orch 상주 루프와 보드의 동작이다.
