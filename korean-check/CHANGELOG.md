# CHANGELOG: korean-check

버전은 `SKILL.md` frontmatter 의 `metadata.version` 과 같은 값을 쓴다.
올리는 기준과 쓰는 형식은 저장소 README 의 "버전과 변경 이력" 을 따른다.

## 1.34.1 (2026-10-28)

- PR 본문과 Dooray 업무 본문을 정형 양식으로 분류해 의미 점검을 건너뛰지 않게 했다

## 1.34.0 (2026-10-28)

- `check.sh` 의 성공 출력을 「표기 검사 통과: N개 파일. 의미 점검은 별도」 로 바꿔 검사기 통과가 의미 점검까지 끝났다는 뜻이 아님을 보인다
- 별도 검토 조건에 「부르는 스킬이 요구할 때」 를 넣었다
- description 에서 채팅 답변을 뺐다. 채팅 답변은 `~/.claude/rules/korean-style.md` 가 맡는다

## 1.33.2 (2026-10-28)

- `korean-examples.md` 의 번역투 예시에 「칸을 더한다」 를 「칸을 추가한다」 로 고친 사례를 더했다

## 1.33.0 (2026-10-20)

- `korean-examples.md` 의 지어낸 이름 예시에 작업 코드명과 코드 안에서만 쓰는 별칭으로 부른 사례를 더했다

## 1.32.0 (2026-10-19)

- 저장소의 `.claude/korean-check-allow.txt` 에 적은 고유명사 안의 발견을 건너뛴다. 한 줄에 문자열 하나이고, 문자열 밖의 금지어는 그대로 잡는다
- 예외 파일은 검사 대상 파일에서 `.git` 이 있는 디렉터리까지만 올라가며 찾는다. `KOREAN_CHECK_ALLOW` 로 경로를 줄 수도 있다
- 한 글자 항목은 검사를 끄는 것과 같아 읽지 않고 stderr 로 알린다
