- 상주 루프의 모델 감지가 이미 본 세대보다 낡은 모델 목록(Codex CLI 가 서버 목록을 받지 못해 낸 실행 파일의 기본 목록)으로 감지 기록을 덮지 않는다. 덮지 않은 날은 `MODEL-LIST-OLDER <이유>` 를 한 번 알리고 다음 날 다시 읽는다.
- 같은 일 두 모델 비교의 숨긴 리뷰에서 모델 이름이 보이지 않는다. 비교 id 는 `compare-<행>-<시작 날짜>-<번호>` 이고, 리뷰어는 모델 줄을 뺀 지시서 사본을 받는다.
- 모델 표가 옛 세대일 때 비교의 지금 모델 쪽 worker 를 새 세대로 적는 법, 순서 파일 `base=A` 의 뜻, 숨긴 리뷰와 평소 리뷰가 모두 같을 때 준비까지 분이 짧은 쪽을 머지하는 규칙을 절차에 적는다.
