# 한국어 표현 예시

문서를 쓰거나 검토할 때 읽는 예시 모음이다. 규칙은 [`korean-style.md`](korean-style.md) 가 소유한다.

## 문장 구성

`korean-style.md` 「문장 구성」 의 규칙을 어긴 문장과 고친 문장이다.

| 고칠 문장                           | 빠진 것   | 고친 문장                            |
| ------------------------------- | ------ | -------------------------------- |
| 그러면 경고가 붙습니다.                   | 대상과 상황 | 이미 작업 중인 파일에도 경고 표시가 붙는다.        |
| 지출 비용 추론 용도의 토큰 카운트 함수의 오류 상황에서 | 조사와 어미 | 지출한 비용을 추론하는 토큰 카운트 함수에 오류가 발생하면 |
| 컨텍스트 압축 전 신중 반영한다.              | 서술 관계  | 컨텍스트가 압축되기 전에 신중하게 반영한다.         |
| 코드로 박는 자리                       | 비유어    | 코드에 명시하는 위치                      |

## 고쳐 쓴 예시

실제로 지적받아 고친 것이다. 검사기가 잡지 못해 여기 둔다.
부분 문자열로 걸면 `증가`, `추가`, `평가` 까지 잡혀 금지어 목록으로 만들 수 없다.

**제목과 표 머리**

| 쓰지 않음 | 씀 |
| --- | --- |
| 무엇을 바꿨나 | 변경점 |
| 무엇이 달라졌나 | 결과 |
| 무엇이 정하나 | 설정 |
| 어떻게 재는가 | 측정 방법 |
| 정답지와 글자가 얼마나 같은가 | 글자 점수 |

**비유를 수치나 동작으로**

| 쓰지 않음 | 씀 |
| --- | --- |
| 262.6초가 그 안에 묻힌다 | 단계 합계 2084.4초의 12.6% 다 |
| 표 분석과 OCR 이 시간을 지배한다 | 표 분석 934.7초와 OCR 610.5초가 전체의 대부분이다 |
| 다른 호출에 밀린다 | 다른 사용자의 호출에 영향을 받는다 |
| 판정할 때 빠지기 쉬운 함정 | 판정할 때 유의할 점 |
| 읽어 가는 곳이 없다 | 아무 데도 쓰이지 않고 버려진다 |
| 조용히 틀린다 | 오류가 드러나지 않는다 |
| 워커를 늘릴 때 그 여유가 돌아온다 | (앞 문장이 CPU 와 메모리를 덜 쓴다고 이미 말하므로 지운다) |
| 로그를 파일에 잇는다 | 로그를 파일에 연결한다 |
| 단계가 겹쳐 돈다 | 단계가 병렬로 수행된다 |

**번역투**

| 쓰지 않음 | 씀 |
| --- | --- |
| 바꾼 설정은 `X` 다. `A` 에서 `B` 로 내렸다 | `X` 설정을 `A` 에서 `B` 로 변경했다 |
| 판정 근거는 ADR-053 이 소유한다 | (밖으로 나가는 글에서는 내용을 본문에 쓴다) |
| 정답지를 세운다 | 정답지를 추가한다 |

**지어낸 이름**

| 쓰지 않음 | 씀 |
| --- | --- |
| 문서 변환기, 파서 | Document Parser |
| 그림 | 이미지 |
| 정점 비트맵 | 줄이기 전 이미지 |
| 공통 부분 수열 비율 | 순서를 지킨 채 겹치는 글자의 비율 |

새로 고친 것이 생기면 이 표에 한 줄을 더한다.

## 실측으로 되돌린 사례

`korean-style.md` 「용어를 옮기지 않는다」 를 어기고 옮겼다가 되돌린 표기다.
이 표는 검사기가 읽지 않는다.

| 옮긴 말   | 원어          | 저장소가 쓰던 표기 |
| ------ | ----------- | ---------- |
| 판      | version     | 버전         |
| 정점     | peak        | 피크         |
| 글자 추출기 | PDF backend | 파싱 백엔드     |
| 절단     | truncation  | 뒷부분 누락     |
| 유입 제한  | rate limit  | rate limit  |
| 틀      | template    | template    |
