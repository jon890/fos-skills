# ADR-021: 보드를 확장 기능 디렉터리에 둔다

- **status**: `accepted`
- **대체**: [ADR-006](006-work-board-in-plugin.md)의 루트 보드 배치. 같은 플러그인으로 배포하는 결정은 유지한다.
- **결정**: 작업 현황 창과 보드 명령·훅·테스트는 `extensions/work-board/`에 함께 둔다. 스킬 원본은 `skills/`, 여러 스킬의 공용 도구는 `tools/`가 맡는다.
- **맥락**: [ADR-020](020-skill-directory-layout.md)으로 스킬과 관리 코드를 나눴다. 보드는 스킬이 아닌 설치 확장 기능이므로 루트에서 별도 영역으로 옮긴다.
- **대안**: 루트에 그대로 두거나 별도 플러그인으로 배포할 수 있다. 별도 배포는 orch와 보드의 설치 경로·버전을 따로 맞추게 하므로 이번 변경에는 포함하지 않는다.
- **결과**: 매니페스트의 훅 경로, orch의 보드 참조, 보드의 스킬 참조, CI와 문서를 함께 바꾼다. `/board` 명령과 저장 상태의 위치는 유지한다. 직접 파일을 부르는 개인 스크립트는 새 경로를 쓴다.
- **검증**: 격리 설치 캐시에서 훅 모듈과 보드 명령을 실행한다. 보드·orch 연동 테스트, 타입 검사와 필수 CI가 통과해야 한다.
