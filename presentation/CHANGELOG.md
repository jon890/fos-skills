# presentation 변경 이력

## 1.0.0 (2026-08-31)

첫 판. 랩 세미나 발표 자료 한 건을 만들면서 겪은 것을 규칙으로 옮겼다.

- `SKILL.md` — 인터뷰 여섯 항목, 파일 규칙, 만드는 순서, 고칠 때의 원칙, 시간 재는 법
- `references/slide-rules.md` — 내용·형태·제목·프롬프트·AI 노출·부 전환·반복 실수·어휘·말 아홉 갈래 판정 규칙
- `references/deck-mechanics.md` — 조작키, 컴포넌트, 재현 애니메이션, 편집 함정
- `assets/deck-template.html` — 골격 한 파일. 예시 장 8개
- `scripts/check-deck.py` — 장 수와 주석 번호, active 장, JS 문법, 하드코딩 잔재, 금지어, 세로 넘침

원본 기준 문서를 옮기면서 고친 것이다.

| 무엇 | 조치 |
| --- | --- |
| 「장 셋으로 압축한다」 아래에 「두 장 각각에」 가 남아 있었다 | 발표 고유 장 구성이라 스킬에서 뺐다 |
| 「두 단계로 보여 준다」 뒤에 세 가지를 나열했다 | 「대화로 보여 준다」 로 고쳐 프롬프트 절에 넣었다 |
| 「회귀 캡처는 지표 다음에 온다」 가 실제 장 순서와 달랐다 | 발표 고유 순서라 뺐다 |
| 「원문은 세션 기록에서 뽑아 쓴다」 | `~/.claude/history.jsonl` 로 고쳤다. 세션 기록에는 최근 것만 남는다 |
| 「데모는 하지 않는다 (미정)」 | 인터뷰 항목으로 옮겼다. 발표마다 정한다 |
| 확정된 장 목록, 결정 현황 | 발표 고유 상태라 뺐다. 확정 장을 고치지 않는다는 규칙만 남겼다 |
| `정점`, `되돌이` 등 전역 매핑 표와 겹친 어휘 | 전역 `korean-style.md` 를 가리키고 발표 고유 금지어만 남겼다 |
