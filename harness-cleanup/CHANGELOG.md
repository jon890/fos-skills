# CHANGELOG: harness-cleanup

버전은 `SKILL.md` frontmatter 의 `metadata.version` 과 같은 값을 쓴다.
올리는 기준과 쓰는 형식은 저장소 README 의 "버전과 변경 이력" 을 따른다.

## 3.21.0 (2026-10-28)

- `scripts/run_checks.py` 가 2단계 검사를 따로 돌리고 스크립트별 종료 코드와 판정을 표로 낸다. 2단계가 이 스크립트를 부른다
- 2단계 통과 조건을 「`--list` 결과와, 돌린 블록과 읽어서 판정한 블록을 이유와 함께 적었다」 로 바꿨다. 무겁거나 혼자 돌아야 하는 블록의 처리 기준을 `references/run-doc-snippets.md` 에 뒀다
- `check_references.py` 가 펜스 코드 블록 안과 브랜치 이름 표기(`docs/branch-naming`)를 깨진 참조로 내지 않는다
- 6단계 재검증이 저장소 CI 워크플로의 job 목록에 대응하는 로컬 명령을 모두 돌리게 했다
- 「조사를 나눠 맡긴다」 에서 Agent 도구 설명과 겹치는 지시를 줄였다
