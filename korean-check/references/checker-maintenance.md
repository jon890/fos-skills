# 검사기 매핑 표 유지보수

## 표에 넣는 기준

매핑 표는 검사기가 실패로 막는 유일한 목록이다.
**누가 봐도 어색한 음차, 비유어, 지어낸 번역어만 넣는다. 넣을지 애매하면 넣지 않는다.**

평범한 우리말은 넣지 않는다. 어색한 쓰임은 의미 점검에서 본다.
버전 뜻의 `판` 은 평범한 우리말이 아니라 version 을 옮긴 말이다. 뺀 뒤 에이전트가 version 을 `판` 으로 옮겨 써서 1.22.0 에서 구절 단위로 다시 넣었다.

영어 원어는 금지어로 넣지 않는다. 원어는 원어 열에 적고, 검사기는 첫 열만 읽는다.

## 부분 문자열로 찾는 데서 오는 제약

검사기는 한국어 금지어를 부분 문자열로 찾는다. 조사가 붙은 형태를 잡으려면 그래야 한다.
그래서 등록할 수 없거나 형태를 골라 등록해야 하는 말이 있다.

| 말 | 처리 | 이유 |
| --- | --- | --- |
| `판`, `정점` | 등록하지 않는다 | `판단`, `판정`, `수정점검` 까지 걸린다 |
| `판을`, `판이`, `판으로`, `판에서`, `판마다`, `판 올리기`, `판 번호`, `판 고정`, `판 접두사` | 버전 뜻으로 쓰이는 구절로 등록한다. `판` 으로 시작하는 금지어는 앞 글자가 한글이면 건너뛴다 | 앞 글자 경계가 있어 `번호판 번호`, `출판 번호`, `초판을 올린다` 같은 `X판` 합성어와 `판단`, `판별`, `판정` 은 걸리지 않는다. `판이하다` 는 `COMPOUND_ALLOW` 에 둔다. 판자 뜻의 `판을 올린다` 는 걸리지만 개발 문서에서는 드물다. `판도` 와 `판의` 는 다른 뜻이 많아 등록하지 않는다 |
| `기계` | `기계가`, `기계로`, `기계적` 만 등록한다 | `기계 학습`, `기계 번역` 까지 걸린다 |
| `시험` | 등록하고 `시험적` 을 `COMPOUND_ALLOW` 에 둔다 | `시험적으로 도입한다` 는 테스트 뜻이 아니다 |

`재시험` 처럼 금지어를 품은 합성어는 함께 걸린다. 테스트 뜻이면 그대로 고친다.
다른 뜻의 합성어가 걸리면 `scripts/korean-style-check.py` 의 `COMPOUND_ALLOW` 에 더하고 테스트에 표본을 넣는다.
