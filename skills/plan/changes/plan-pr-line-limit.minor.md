- 계획 검사가 신규 파일도 종류별 평균 줄 수(운영 코드 60줄, 테스트 130줄, 문서 60줄)로 세어 PR 줄 수 추정에서 「미상」 으로 빠지지 않는다. 계수의 실측 근거는 `plan-size.md` 의 「줄 수 추정」 에 있다.
- 줄 수 추정을 운영 코드, 테스트, 문서로 나눠 보인다.
- 레포 설정 「PR 줄 수 상한」 을 읽어 운영 코드 추정이 상한의 80% 를 넘으면 phase 별 추정과 함께 경고하고, 상한을 넘으면 위반으로 낸다. 상한은 정수, JSON 키, JS·TS 상수로 가리킨다.
- 신규 파일이 줄 수에 더해져 `.github/pr-size.json` 의 등급과 크기 경고가 전보다 높게 나올 수 있다. lock 파일, 빌드 결과물, 파일째 지우는 운영 코드, 이동은 줄 수에서 뺀다.
- 레포 설정 「PR 줄 수 운영 코드」 로 운영 코드로 셀 경로를 정하고, `index.json` 의 `size_exception` 으로 사용자가 정한 크기 예외를 적는다.
