# CHANGELOG: docs-audit

버전은 `SKILL.md` frontmatter 의 `metadata.version` 과 같은 값을 쓴다.
올리는 기준과 쓰는 형식은 저장소 README 의 "버전과 변경 이력" 을 따른다.

## 5.0.1 (2026-11-06)

- 심볼릭 링크로 부른 진입도 import.meta.main 이 없는 Node 24.0·24.1 에서 일을 하도록 직접 실행 판정을 실체 경로로 비교한다

## 5.0.0 (2026-11-06)

- 호환성: 스크립트 둘을 `.py` 에서 Node 24 의 `.ts` 로 바꿨다. `node "$SKILL_DIR/scripts/run_static_check.ts"` 처럼 확장자만 바꿔 부른다
- 옵션, 출력, 종료 코드는 그대로다. `ADR_DIR` 인자도 이전처럼 받기만 한다. 이 스킬을 쓰려면 Node 24 이상이 필요하다

## 4.x

- 깨진 링크·앵커와 ADR 색인 검사를 `static_check.py` 에서 빼고 2단계가 plan 의 `adr-docs.ts check --scope` 를 함께 부른다
- ADR 감사에서 확정된 과거 맥락을 보존하고 기존 타입 누락을 오류로 보지 않는다.
- 하네스 지침 감사를 `harness-cleanup` 이 맡는다는 경계 문장을 그 스킬이 설치돼 있을 때만 성립하는 조건부 문장으로 바꿨다
- 레포 오버레이 절을 1단계 범위 판정으로 옮기고, ADR 규칙과 계획서 참조 원칙은 소유 문서만 가리키게 했다
- 호환성: 호출 이름과 번들 경로를 `docs-check` 에서 `docs-audit` 로 바꿨어요. 새 이름으로 호출해요.

## 3.x

- ADR 이 현재 도메인 규칙의 원본 노릇을 하는 곳과, 설정 값과 도메인 문서 설명이 어긋난 곳을 발견으로 보고해요.
- 완료 계획의 보존 정책과 증거 인계를 확인한 뒤 제거 후보로 분류해요. 기본 완료 기준은 구현 PR 머지로 바꿨어요.
- 기능별 책임 문서와 참조한 공유 계약을 감사 범위로 인식해요.
- `scripts/run_static_check.py` 가 정적 검사를 실행하고 종료 코드와 판정을 표로 내요. 발견·유지 유형으로 분류한 정적 위반은 의미 검사로 넘겨요.
- ADR 색인의 링크 문구·표 형식과 하위 폴더를 인식하고, `WARN LISTED_ITEMS` 로 책임 설명에 늘어놓은 목록을 알려요.
- 모노레포 판정을 `planning/scripts/overlay_paths.py --skill docs-check` 호출로 바꿨어요. 하위 프로젝트 오버레이를 루트보다 먼저 읽어요.
- 호환성: 독립 검토 단계를 없앴어요. 의미 조사는 읽기 전용으로 나눌 수 있고, 직접 조사해도 발견과 증명을 남겨요.
- 수정 뒤 실제 실행한 검증 명령과 결과를 보고하고, 일부만 확인했으면 그 범위를 밝혀요. 세부 변경 이력은 git 에 남아 있어요.

## 2.x

- 실행 절차를 단계마다 통과 조건이 있는 6단계로 정하고, 범위 판정에서 각 문서가 무엇을 담는지 함께 정한다
- 정적 검사를 `scripts/static_check.py` 로 옮기고 앵커 링크도 검사한다. 한글 이름 문서가 검사에서 빠지던 문제를 고쳤다
- `status: superseded` 인 ADR 에는 부패 축과 자명성 축을 적용하지 않는다
- 구현이 끝난 `tasks/` 의 계획서를, 그 결정이 `docs/` 나 ADR 에 남았을 때 제거 후보로 판정한다
- 문서가 계획서를 번호로 가리킨 자리를 `PLAN_REF` 로 찾는다
- 조사를 읽기 전용 하위 에이전트에게 나눠 맡기고, 회신 형식을 리포트의 발견 하나와 같게 받는다
- 표 열 수 검사가 이스케이프된 `\|` 를 열 구분자로 세던 오탐을 고쳤다
- `static_check.py` 를 스킬 번들 경로로 불러, 상대 경로로 불러 종료 코드 2 로 멈추던 문제를 고쳤다

## 1.x

- 버전 체계를 도입했다
- 정적 검사가 미추적 신규 문서와 공백이 든 파일 이름도 검사한다
- 링크 검사가 `dooray://` 같은 앱 스킴과 `/` 로 시작하는 경로를 건너뛴다
- ADR Index 동기화가 본문은 헤딩의 번호만, INDEX 는 표형과 목록형의 등재 항목만 센다. `INDEX.md` 가 없으면 검사하지 않는다
- ADR 줄 수로 과대화를 판정하던 검사를 없앴다. 과대화는 의미 검사가 판정한다
- 범위를 주지 않으면 현재 경로와 변경 파일에서 가장 좁은 범위를 고르고, 정적 위반이 있으면 종료 코드 1 을 낸다
