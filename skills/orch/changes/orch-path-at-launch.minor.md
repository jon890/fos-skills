- 공통 지시서 틀의 명령 블록에서 실행기 경로를 푸는 한 줄과 설명을 지우고 명령을 `orch …` 만 남긴다. 저장소의 사본은 `orch spec sync-common` 으로 맞춘다
- `orch worker launch` 가 새 터미널 전에 worker 셸이 PATH 로 `orch` 를 찾는지 보고, 못 찾으면 `orch doctor install-cli` 를 안내하며 멈춘다
- 이어 쓰는 터미널(`--terminal`)과 원격 환경 옵션(`--on`, `--environment`, `--pairing-code`)으로 띄우는 worker 는 이 확인을 건너뛴다
- `orch worker resume` 이 같은 확인을 하고, 사본이 깔려 있으면 새 터미널 명령 앞에 `export PATH=…` 를 더한다
